# 2.3.3 추가 수정 인수인계

2026-11-02. 기존 2.3.3 위에 합치기 HUD, 임무, 테마, 행사 연출을 추가한 작업이다.

- 일일과 주간의 강화/연수 강제 목표는 새 추첨에서 제외한다. 기존 완료/수령 가능 임무는 유지한다. 미완료 불가 임무만 다른 종류로 교체하고 기준값을 새로 잡는다.
- 일일 미션은 하루 한 번 무료 교체한다. `dm.swapped`를 기본값과 sanitize에 추가했다. 완료/수령 가능/완주 후 교체 불가.
- 주간 대체 목표에 퍼즐5판, 합치기주문10개, 참나무60번을 추가했다. 상자는100/250/350/500/650점이며 총 보상과 수령 플래그는 유지한다.
- 테마 원본은 art/v300-theme2 커밋7c8ecbc이다. 유치원/초등/중학 우주·레트로 지도6장을 고화질WebP 및 내장 예비 이미지로 연결했다. 스티커6개도 연결했다. 고등 지도는3.0용으로 제외.
- 학예회: 지도 가장자리 음영과 두 가지 색 조명, 행사 종료 시 제거. 졸업사진: 가랜드와 반짝이, 사진기 위치를 학교급 광장에 맞춤. 클릭 통과와 동작 줄이기 적용.
- 코드 원본은 dev/forest-school.html. index.html은 build_gh.py로 생성한다. 버전은2.3.3 유지. 게임 공지는 이전에 사용자가 승인한 세 줄을 유지한다.
- 별도 보안 초안 PR#105는 이 변경에 포함하지 않았다. 고등학교와 학교 프로젝트 등 큰 개편도 포함하지 않았다.
