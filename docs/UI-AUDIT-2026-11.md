**값을 바꿔서 본 화면**

- 퍼즐 선생님 도움 쓰기: 하던 판의 helps를 다람쥐 2, 부엉이 1, 곰 1로.

- 6번(고르게 올리기)과 7번(별 조각 6/0)은 화면에서 본 것이지만 까닭이 셈 쪽이라 고치려면 ChatGPT 검토가 필요해요. 6번은 all 저장 그대로(값을 바꾸지 않음), 7번은 별이 4로 채워진 all 저장에서 봤어요.

### 글과 용어

**확인하지 못한 화면**

- 흔들기만 하는 18곳과 긴 알림은 코드로만 셌어요.

**값을 바꿔서 본 화면**

- 텃밭: `openGd()`로 열고 단추는 직접 눌렀어요.

**그 밖에 확인한 것**

- **맞춤법**: "되요", "할께요", 붙여 쓴 "해주세요" 같은 것은 화면 글에서 0곳이었어요.

- **겹치는 문장**: 같은 문장이 두 곳 이상인 것 139개, 세 곳 이상 37개인데 대부분 학교급마다 되풀이되는 퀘스트 글이에요. 단축권이 없을 때 안내는 "광고를 보면 5분권 6장을 받아요"(12800, 13156, 26640)와 "광고를 보거나 문방구에서 살 수 있어요"(13270) 두 가지예요.
