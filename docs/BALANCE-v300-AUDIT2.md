# 3.0.0 재화 분석 다시 재기 (2026-11-02, Claude)

조정안 2번. 기준 코드: feat/v300 2bc259b(조정 1, 3, 4, 5, 6, 7 적용 뒤). 결과 파일: `docs/balance-v300b/`.

## 무엇을 고쳤나

- **시작 상태 두 가지**
  - `mid`: 초등학교 졸업 직후. 시설은 6학년 상한, 학력 Lv.15, 대결 1200점(동), 대결 1판.
  - `high`: 중학교 졸업 직후. 무지개 리그 2500점, 대결 20판(hw9를 마친 최소). 예전 모형은 금 리그로 입학해서 hw9 때문에 실제로 나올 수 없는 상태였어요.
- **중학교 시스템 퀘스트**: 동아리, 대항전 연습, 반장 선거, 간식 뽑기, 운동회를 실제 게임 함수로 하루 한 번씩 해요. 서로 다른 동아리로 발표회를 열어요.
- **문제집**: 하루 2권까지.
- **경우**: 하루 10분과 15분, 광고 0, 3, 5편, 씨앗 42 하나. 모두 12경우.
- 행동 순서는 예전 모형과 같아요. 예를 들어 광고를 먼저 보고 남은 시간에 대결을 해요. 그래서 이 결과는 규칙대로 움직인 비교 실험이고, 실제 이용자가 걸리는 날짜를 예측한 것은 아니에요.

## 읽는 법

- **고등학교는 약 20~24일**에 끝나요. 목표(한 학년 7일, 3년 21일)와 거의 같아요. 예전 보고서의 40~65일은 hs36(무지개 리그) 대기 때문이었어요.
- 고등학교에서 가장 길게 멈추는 곳은 **hs12(1학년 1학기 방학식, 대도시 조건)**이에요. 2~5일 걸려요.
- **중학교는 약 21~28일**이에요. 목표 15일(한 학년 5일)보다 길어요. 중학교는 이미 출시된 구간이라 이번에는 고치지 않았어요.
- 하루 10분에 광고 5편인 경우만 31~51일로 길어요. 모형이 광고 5편(2분 30초)을 먼저 보면 대결(1분 30초)을 할 시간이 자주 모자라서, 판 수 숙제(hs19, hs36, hw7, hw8)를 기다려요. 사람이라면 대결을 먼저 할 수 있어서, 모형 순서 때문에 생긴 결과로 봐요.
- **황금(7일)**: 광고 0편 약 20개, 광고 3~5편 약 40개예요. 예전(광고 3편 이상)에는 약 79개였어요.
- **정수(7일)**: 퍼즐 1500점 가정에서 547개가 들어오고, 문제집 하루 2권으로 약 430~450개를 써요.
- 고등학교 분치 배수를 8에서 4로 줄여도(조정 6) 끝나는 날은 같았어요.

## 건물 한 레벨 값(수업료 분) — 조정 6의 근거

`dev/balance_v300_levelmin.py`로 쟀어요. 시설을 그 학년 상한의 30%에 두고 다음 레벨 값의 가운데 값을 `rate() × 60`으로 나눴어요. 선생님과 특전 배수가 없는 상태라 절댓값은 크게 나오지만, 학교급끼리 비교하는 데 썼어요.

| 학교급 | 1학년 | 마지막 학년 |
|---|---|---|
| 유치원 | 0.6분 | 0.8분 |
| 초등학교 | 4~6분 | 120~190분 |
| 중학교 | 630~820분 | 1500~2200분 |
| 고등학교 | 180~220분 | 350~460분 |

고등학교 레벨은 수업료로 따지면 중학교의 약 4분의 1~3분의 1이에요. 그래서 숨은 2^학교급(고등학교 8배) 대신 이름 있는 표 `TIER_X = [1, 2, 4, 4]`로 바꿨어요. 유치원부터 중학교까지는 예전과 같아요.
