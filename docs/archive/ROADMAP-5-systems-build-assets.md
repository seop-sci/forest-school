### 대학교
- **4.0.0 학과 선택**: 학교마다 전공 2~3개(생명, 공학, 예술 등)를 골라 특화해요. 전공마다 건물 보너스와 전용 장식이 달라요. 교수님 호칭과 함께 학교 정체성이 생겨요. 졸업할 때 전공을 바꿀 수 있어요. 과목 레벨이 높은 과목의 전공 보너스가 커요.
- **4.1.0 대학 축제**: 학생회관에서 게임 시계 기준 한 달에 한 번 큰 축제. 랭킹 상위 학교의 동물이 놀러 와서 선물을 줘요. 축제 동안 소풍, 간식 뽑기, 동아리 발표회가 모두 2배.
- **4.2.0 교환학생**: 다른 플레이어 학교(랭킹이나 학교 구경에서 고름)와 학생 한 명을 게임 시계 기준 한 주 동안 바꿔요. 온 학생은 그 학교 간판 색 목도리를 하고 지도를 걸어 다니고, 돌아올 때 그 학교 전공의 특산 장식을 가져와요. 서버에 교환 기록 필요(상대는 수락 없이 자동, 상대 학교도 같은 보상).

### 대학원
- **5.0.0 연구 트리**: 정수와 도토리를 써서 영구 보너스를 연구해요(수업료, 행사 보상, 소풍 수확, 오프라인 상한, 조교 자리). 최종 성장 축이자 정수의 마지막 소비처. 졸업해도 연구는 남아요.
- **5.1.0 조교 파견**: 대학원생을 아래 학교급 건물에 조교로 배치해요. 조교가 있는 건물은 수입이 오르고 가구 올리는 값이 조금 싸져요. 조교 자리는 연구 트리에서 늘려요. 대학원이 학교 전체와 이어지는 마지막 조각이에요.
- **5.2.0 논문과 숲속 학회**: 끝낸 연구를 논문으로 묶어요(연구 3개가 논문 1편). 분기마다 열리는 숲속 학회에 논문을 내면 전체 플레이어 사이에서 논문 수와 연구 깊이로 순위를 매겨요. 상위는 그 분기 한정 칭호와 장식, 참가만 해도 황금 도토리. 게임의 마지막 랭킹이에요.

## 8. 공사 시간과 시간 단축권

- **3.0.0에서 정리 (2026-11-02 지섭 결정, 2.3.5에 들어감)**: 무료 즉시 완공을 건물마다 하루 1번에서 학교 전체 하루 3번으로. 하루 한 번 접속하는 사람은 공사가 다음 날이면 끝나 있어서, 진행 속도는 시간권보다 '접속 한 번에 몇 레벨 올리나'(무료 완공 수)가 좌우해요. 2.3.5부터 비버 시설 선생님이 공사 시간을 최대 -20%.
- **지금 공사 시간 (2.3.0, 2026-10-30 지섭 결정)**: 처음 짓기는 모든 학교급 10초. 레벨 공사는 유치원 5초, 초등 1~3학년 30초~5분, 4~6학년 1~20분, 중1 5~30분, 중2 10~45분, 중3 15분~1시간, 고등학교 30분~1시간, 대학교 30분~2시간, 대학원 1~3시간.
- **즉시 완공 단추 (2.3.0)**: 건물 창의 업그레이드 단추 옆 ⚡ 작은 단추(빨간 1 배지)와 공사 중 '즉시 완공' 단추로 원할 때 써요. 2.3.5부터 학교 전체 하루 3번(칩 '오늘 즉시 완공 n/3').
- **숲의 정수 즉시 완료 (2.3.0)**: 공사 중 보라색 단추. 남은 시간 5분 이하는 정수 2, 그보다 길면 10분마다 4. 확인 창에 동그란 체크 '오늘은 다시 묻지 않기'.
- **'단축권 자동 사용' (2.3.0)**: 공사 창의 '바로 줄이기'를 이 이름으로 바꿨어요.

## 9. 언제든 넣을 수 있는 작은 것

- **끊김 줄이기 (2026-11-04 조사, 2026-11-06 지섭 "더 세우자")**: 모든 학교급에서 매 프레임 스타일 다시 계산이 커요. 큰 몫은 학생 16명 위치를 매 프레임 바꾸는 것, 반딧불 8개, 지도 밖 UI의 끝없는 CSS 움직임(칩 반짝임 등). 지도 밖 UI를 숨기면 프레임이 나아졌어요(평균 41 → 49fps). 3.1.1(밤 학생 그리기 쉬기)과 3.2.0(밤 그림 한 장으로, 밤에 지도 움직임 멈춤)에 일부 넣었어요. **다음 후보(본부 제안, 모습은 그대로 두는 것부터)**: (1) 비 오는 날 화면 전체를 다시 그리는 비 줄기 움직임(background-position)을 가벼운 방식(transform)으로, 하늘에만 (2) 그림자와 빛 번짐(box-shadow, filter)을 매 프레임 바꾸는 반짝임 움직임 약 10개를 같은 모습의 가벼운 방식(opacity, transform)으로 (3) 창이나 다른 탭이 지도를 덮고 있을 때와 앱이 화면 밖일 때 지도와 UI 움직임 멈추기 (4) 학생 걸음 갱신을 매 프레임에서 조금 덜 자주로 (5) 끝없는 CSS 움직임 70개 정리. 칩 반짝임을 아예 없애는 것처럼 모습이 바뀌는 것은 지섭 결정.

## 10. 에셋을 만들 때 지킬 것

1. **그림에 글자를 넣지 않아요.** 건물 이름, 레벨, 숫자, 미션 내용, 버튼 글자는 게임이 직접 써요. 시안 그림에는 글자가 있어도 되지만, 실제 에셋은 글자 없이 만들어요.
2. **배경 지도는 건물 없이** 길과 숲, 물, 울타리만 그려요. 학교급별로 6장(유치원, 초등학교, 중학교, 고등학교, 대학교, 대학원)이에요.
3. **지도 크기는 1024×1536(세로)**이에요. 휴대폰에서는 양옆이 조금 잘리고 위아래는 UI가 덮으니, 건물 자리는 가로 15%~85%, 세로 22%~80% 안에 두어요.
4. **건물은 하나씩 배경이 투명한 PNG로** 만들어요. 건물마다 "지어진 모습"과 "공사 중(잠김) 모습" 두 장이 필요해요. 놀이터(유치원)와 운동장(초등학교부터)은 따로 그려요. 지붕이 있는 건물은 지붕만 뗀 조각(밝은 회색)도 주세요. 게임이 꾸미기 배경에 맞춰 색을 입혀요.
5. **건물 자리 표**도 같이 주세요. 지도마다 건물 이름과 위치(가로 %, 세로 %)를 적어 주면 돼요. 1.7.3부터 게임은 빈터(울타리 안 땅)의 가운데와 너비로 건물을 놓아요. 표에는 빈터 가운데와 빈터 너비(%)를 적어 주세요. 새 건물 그림을 넣을 때 바닥 섬 값(BLD_ISL)을 재서 적고, 지도에 띄워 울타리에 맞는지 눈으로 확인해요(3.1.1 학생회관).
6. **UI 조각도 글자 없이 따로** 만들어요. 밝은 판과 어두운 판 두 가지예요.
   - 위쪽: 학교 정보 카드, 재화 칸, 학교 파워 배지
   - 홈: 미션 패널, 오른쪽 세로 버튼 틀, 건물 이름표, 자물쇠 배지
   - 버튼: 큰 버튼, 작은 버튼, 누를 수 없는 버튼
   - 진행 막대, 창(팝업) 틀, 아래 탭 막대
   - 아이콘: 탭 5개(홈, 선생님, 공부, 졸업, 상점), 오른쪽 버튼 4개(퀘스트, 랭킹, 도감, 이벤트), 톱니바퀴, 재화 6개(도토리, 황금 도토리, 숲의 정수, 수료증, 기금, 쪽지)
7. **계절 장식 스티커**: 상점 배경 5종(봄 벚꽃, 여름 바다, 가을 단풍, 겨울 눈꽃, 크리스마스)마다 장식 3~5개. 지도를 새로 그리지 않고 장식을 올려서 꾸며요.
8. **파일 형식**: PNG, 배경 투명. 크기는 Claude가 줄여서 넣어요.
9. 그림에 기호가 우연히 다른 상징처럼 보이지 않게 봐요(2.2.0 야간 건설 아이콘의 초승달과 망치가 낫과 망치 상징처럼 보여 작업지시서 38로 다시 그림).
10. 중간 업데이트와 고유 시스템 그림은 그 버전을 시작할 때 Codex 작업지시서를 따로 만들어요. 작업지시서 22까지 그림은 모두 받았어요(2026-10-27). 새 학생 6종은 빨간 목수건 판으로 다시 받았어요(art/v201).
11. 게임 그림은 이미지 생성 기능으로 만들고 코드로 그리지 않아요. 그림이 필요하면 작업지시서를 먼저 채팅에 보여 줘요. 3.1.2에서 코드로 그려 두었던 그림 31장을 새 그림으로 바꿨어요(작업지시서 52).
12. 게임 안 그림은 base64 글자로 원본 파일에 들어 있어요. 코드 이름을 한꺼번에 바꿀 때 그림 줄까지 바뀌면 그림이 깨져요(#119에서 83장, 3.1.0에서 되돌림). 바꾸기는 코드 줄에서만 하고, 바꾼 뒤 그림 키 값이 그대로인지 비교해요. 3.2.0부터 배포판(index.html)을 만들 때 dev/build_gh.py가 그림을 img/a 파일로 꺼내요(원본과 시험은 그대로 base64). 웹판은 GitHub Pages에서 이 파일을 읽고, 안드로이드와 토스는 앱 안에 담아요.
