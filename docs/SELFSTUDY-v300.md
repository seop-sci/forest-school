# 3.0.0 낮 자율학습 예약

낮에만 접속하는 이용자가 고등학교 메인 퀘스트에서 막히던 문제를 해결한다.

- 한국 시간06~20시에는 오늘20시 시작을 예약한다. 20~다음06시에는 해당 밤을 바로 시작한다. 06시 전에는 다음 밤을 미리 예약하지 않는다.
- 한 밤에 한 번, 예약 뒤 과목 변경/취소/자동 반복 없음. 과거 밤으로 소급 예약하지 않는다.
- ns.n은 기존 시작 기록을 유지하면서 새 예약도 준비 횟수로 인정한다. ns.at은 예약/시작 시각, ns.fin은 아침 결과를 받은 횟수. 두 새 필드는 기본0이고 sanitize에서 읽는다. 유효하지 않은 날짜는 비운다.
- 기존 ns.at 없는 저장의 활성 밤은 이전 방식의 시작 시각을 사용한다. 새 밤부터 실제 시작 이전의 시간은 보상에 포함하지 않는다.
- hs9/hs26은 각각 준비1/3회. hs22는 아침 결과1회로 완료한다. 옛 nsAway 기록도 인정해 진행이 후퇴하지 않게 한다. 퀘스트 ID/보상값 유지.
- 기존 기숙사 상한/사감 배율/아침XP 값 유지. 낮에는 밤 추가 보상이 적용되지 않고 XP도 아침06시 이후 한 번만 지급한다. 오프라인 보상은 실제 기간과 해당 밤이 겹칠 때 기존 방식으로 계산한다.
- 시험:s37,s102,s104,s105. 화면390밝은/360어두운. 서버 규칙/앱ID 변경과 main 배포/출시 빌드는 없음.

## 실행 결과

- s37, s102, s104, s105 최종 PASS. s105는 실제 새로고침 뒤 예약 복원도 확인한다.
- s4의 옛 저장 시나리오는 변경 전 코드에서도 초보자 안내가 탭을 막아 시간 초과했다. 이 시험은 저장/졸업을 검사하므로 해당 옛 저장 fixture에만 튜토리얼 건너뜀 상태를 지정했다. 게임의 튜토리얼 동작이나 공통 시험 helper는 바꾸지 않았다. 최종 재실행은 PASS이며 결과 파일 s4res.json의 errors도 비어 있음을 확인했다.
- 이미지 생성/새 그림/운영 규칙 수정 없음. 기본 보상 수치와 퀘스트 보상 수치 유지.
