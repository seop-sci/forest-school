# 핫픽스 (원격 설정, 2.0.0부터)

업데이트(스토어 검수) 없이 고칠 수 있는 것을 저장소 맨 위 `live.json` 하나로 바꿔요. main에 합치면 1~2분 뒤 웹 주소(https://seop-sci.github.io/forest-school/live.json)에 올라가고, 웹, 안드로이드, 토스 판이 켤 때 읽어요(2026-10-27 지섭 결정).

- 코드는 받지 않아요. 숫자, 공지, 기능 끄기만 받아요. 코드 오류는 업데이트로 고쳐요.
- `live.json`만 바꾸면 안드로이드 빌드는 돌지 않아요(.github/workflows/android.yml은 index.html과 app/만 봐요).
- 게임은 받은 것을 기기에 남겨 두고, 인터넷이 없을 때는 마지막으로 받은 값을 써요. 받은 적이 없으면 게임 안 값 그대로예요.
- 토스 미니앱에서 바깥 주소를 읽을 수 있는지는 토스 테스트(QR)로 한 번 확인해요. 안 되면 토스 판은 업데이트로만 고쳐요.

## 모양

```json
{
  "v": 2,
  "notices": [
    { "id": "2026-11-05-a", "date": "2026-11-05", "tag": "알림", "title": "서버 점검 안내", "lines": ["11월 6일 새벽 2시~3시 랭킹이 잠시 멈춰요"] }
  ],
  "cfg": { "pz.perDay": 12 },
  "off": ["merge"],
  "maint": { "title": "서버 점검", "msg": "더 좋은 학교를 위해 점검하고 있어요.", "until": "11월 6일 새벽 3시" }
}
```

- `v`: 바꿀 때마다 1씩 올려요(기록용).
- `notices`: 게임 안 공지 위에 얹어요(최대 10개). `id`는 겹치지 않게, `date`는 YYYY-MM-DD, `lines`는 줄마다 하나(최대 20줄). 접속할 때 새 공지 창 규칙(7일, 일주일간 열지 않기)도 똑같아요. 업데이트 공지(패치노트)는 지금처럼 게임 안 `NOTICES`에 넣고, 급한 알림만 여기에 넣어요.
- `cfg`: 아래 표의 이름만 받아요. 범위를 넘으면 끝 값으로 맞춰요. 빼면 게임 안 값으로 돌아가요.
- `off`: 잠시 끌 기능. `puzzle`(숲속 퍼즐), `merge`(숲속 합치기), `event`(이벤트), `battle`(숲속 대결, 2.0.1부터), `weather`(날씨, 2.1.3부터. 끄면 맑음).
- `maint` (2.1.0부터, 점검 모드): 있으면 게임을 켤 때 점검 덮개가 화면을 덮어요. `msg`(꼭 있어야 해요, 300자까지), `title`(빼면 '점검 중이에요'), `until`(끝나는 때 글자, 보여 주기만 해요). 점검 중에는 1분마다 live.json을 다시 읽고, `maint`를 지우면 저절로 열리며 '점검이 끝났어요' 알림이 떠요. 인터넷에서 받았을 때만 따르고 기기에 남기지 않아요(인터넷이 없으면 갇히지 않아요). 제목을 3초 안에 다섯 번 누르면 그 기기는 이번만 들어가요(지섭 확인용). 랭킹과 클라우드 저장까지 막으려면 Firebase 규칙을 잠시 잠가요(지섭이 콘솔에서).

| 이름 | 뜻 | 게임 안 값 | 범위 |
| --- | --- | --- | --- |
| `pace` | 게임 속도(수업료 배율) | 0.2 | 0.1~0.4 |
| `pz.perDay` | 숲속 퍼즐 하루 보상 판 | 10 | 3~30 |
| `pz.adMore` | 광고로 더 받는 판 | 3 | 0~10 |
| `pz.adMax` | 퍼즐 광고 하루 횟수 | 1 | 0~5 |
| `mg.adN` | 합치기 광고 하루 횟수 | 2 | 0~5 |
| `mg.adE` | 합치기 광고 에너지 | 50 | 10~200 |
| `mg.regen` | 합치기 에너지 1 차는 시간(ms) | 60000 | 20000~300000 |
| `ev.scale` | 이벤트 미션 도토리 배율(다음 회차부터) | 0.667 | 0.3~1.5 |

## 하는 법
1. 지섭이 "핫픽스 해 줘"라고 하면 Claude가 `live.json`을 고친 브랜치와 PR을 만들어요.
2. 지섭이 승인하면(업데이트하자) main에 합쳐요. 1~2분 뒤 다음에 켜는 사람부터 바뀌어요.
3. 시험: `python3 dev/s69test.py`
