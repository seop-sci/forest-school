# 숲속 동물 학교 테스트판

도토리를 모아 숲속 학교를 키우는 방치형 게임이에요. 토스 미니앱으로 내기 전에 몇 명이 먼저 해 보면서 속도와 재미를 확인하려고 GitHub Pages에 올렸어요.

- 게임 주소: https://seop-sci.github.io/forest-school/
- 저장: Firebase 실시간 데이터베이스 (테스터마다 따로 저장돼요)

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 게임 전체예요 |
| `config.js` | Firebase 연결 설정이에요. 비어 있으면(null) 이 기기에만 저장하는 체험판으로 열려요 |
| `database.rules.json` | 데이터베이스 규칙이에요. Firebase 콘솔의 규칙 탭에 붙여 넣어요 |
| `og.png` | 카카오톡에 링크를 보낼 때 보이는 미리보기 그림이에요 |

## 처음 한 번 설정하기

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 **프로젝트 추가**를 눌러요.
2. 이름은 `forest-school`처럼 적어요. Google 애널리틱스는 꺼도 돼요.

생태계 게임(eco-battle) 프로젝트와 따로 만들면 수업에 쓰는 규칙과 섞이지 않아요.

### 2. 실시간 데이터베이스 만들기
1. 왼쪽 메뉴 **빌드 > Realtime Database > 데이터베이스 만들기**
2. 위치는 **싱가포르(asia-southeast1)**, 보안 규칙은 **잠금 모드로 시작**을 골라요.
3. **규칙** 탭에서 원래 글을 모두 지우고 `database.rules.json` 내용을 붙여 넣은 뒤 **게시**를 눌러요.

### 3. 익명 로그인 켜기
**빌드 > Authentication > 시작하기 > 로그인 방법 > 익명 > 사용 설정 > 저장**

테스터는 회원가입 없이 바로 시작하고, 기기마다 익명 id가 하나씩 생겨요.

### 4. 웹 앱 등록하고 config.js 채우기
1. 왼쪽 위 톱니바퀴 > **프로젝트 설정 > 일반 > 내 앱**에서 웹(`</>`) 아이콘을 눌러요.
2. 앱 이름을 적고 등록하면 `firebaseConfig`가 보여요.
3. 그 안의 값을 `config.js`의 `null` 자리에 옮겨 적어요. `databaseURL` 줄이 꼭 있어야 해요. 없으면 2번을 마친 뒤 프로젝트 설정 화면을 다시 열어 복사해요.

### 5. GitHub Pages 켜기
저장소 **Settings > Pages > Build and deployment**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 눌러요. 1~2분 뒤 게임 주소가 열려요.

### 6. 잘 붙었는지 보기
게임의 **설정 > 정보 > 저장 위치**에 `서버 (방금 저장)`처럼 보이면 성공이에요. 문제가 있으면 그 자리에 까닭이 나와요.

| 저장 위치에 보이는 말 | 고칠 곳 |
| --- | --- |
| 서버를 연결하기 전 체험판 | `config.js`가 아직 null이에요 |
| Firebase에서 익명 로그인을 켜 주세요 | 3번 |
| 데이터베이스 규칙을 확인해 주세요 | 2번의 규칙 |
| config.js에 databaseURL이 없어요 | 4번 |
| config.js의 Firebase 설정을 확인해 주세요 | 4번에서 값을 잘못 옮겼어요 |

## 테스트 현황 보기
설정 탭 맨 아래 **버전** 줄을 빠르게 다섯 번 누르면 개발자 메뉴가 열려요. **테스트 현황 보기**에서 테스터마다 어디까지 했는지(학교, 학년, 퀘스트), 얼마나 했는지(플레이 시간, 접속 횟수, 출석, 광고), 마지막으로 언제 들어왔는지 볼 수 있어요.

같은 기록이 Firebase 콘솔의 Realtime Database 데이터 탭 `forest/stats` 아래에도 있어요.

테스터가 랭킹에 이름을 올리면 그 이름으로 보이고, 아니면 `이름 없는 학교 #K7QM`처럼 학교 번호로 보여요. 학교 번호는 게임의 설정 > 정보에서 볼 수 있어요.

## 다른 기기에서 이어하기
카카오톡 안에서 열던 게임을 사파리나 크롬으로 옮기거나 휴대폰을 바꿀 때 써요.

1. 원래 기기: **설정 > 다른 기기에서 이어하기 > 코드 만들기**
2. 새 기기: 게임을 열고 같은 메뉴에 코드를 넣어요. 원래 기기에서 **이어하기 링크 복사**를 눌러 링크를 보내면 코드를 넣지 않아도 돼요.

코드는 30분 동안 한 번만 쓸 수 있어요.

## 서버에 저장되는 것

| 자리 | 내용 | 볼 수 있는 사람 |
| --- | --- | --- |
| `forest/saves/<id>` | 게임 저장 | 본인만 |
| `forest/rank/<id>` | 랭킹 이름, 학교 점수 | 게임을 연 사람 모두 |
| `forest/stats/<id>` | 진행 단계, 플레이 시간, 접속 횟수 같은 테스트 기록 | 게임을 연 사람 모두 |
| `forest/moves/<코드>` | 다른 기기로 옮기는 학교 (30분) | 코드를 아는 사람 |

이름이나 연락처 같은 개인 정보는 받지 않아요. 랭킹 이름은 테스터가 직접 정해요. `config.js`의 값은 공개돼도 괜찮고, 데이터는 규칙이 지켜요.

## 비용
Firebase 무료 요금제(Spark)로 충분해요. 테스터 몇 명이면 저장 공간 1GB, 한 달 다운로드 10GB 한도에 한참 못 미쳐요.

## 기록 지우기
- 한 사람: Firebase 콘솔 데이터 탭에서 `forest/saves`, `forest/rank`, `forest/stats` 아래 그 사람의 id를 지워요.
- 모두: `forest`를 통째로 지워요. 테스터 기기에 남은 저장은 다음에 열 때 다시 서버로 올라가요.
- 테스터가 처음부터 하고 싶을 때: 게임의 **설정 > 처음부터 다시**

## 게임을 고칠 때
게임은 Claude 화면의 시제품과 같은 코드예요. 고칠 때는 `index.html`만 새로 만들어 올리고 `config.js`는 그대로 둬요.

## 황금 도토리와 꾸미기 상점
아래 **상점** 탭에서 열어요. 구글 계정을 처음 연결하면 수료증 15장, 기금 3, 황금 도토리 30개를 선물로 줘요.
- 모으는 곳: 광고를 끝까지 보면 1개 (하루 10개까지), 상점에서 광고 보고 2개 (하루 5번), 출석 도장 1개 (7일째 5개), 메인 퀘스트 한 장 3개, 종업식 2개, 졸업식 10개
- 쓰는 곳: 테마 세트, 학생 모자와 목 장식, 학교 지붕(벚꽃 학교, 눈 오는 학교), 칠판 색, 부스터(1회 사용 가능: 특식 데이 30분, 2시간 건너뛰기, 도토리 자동 줍기 1시간)
- 테마 세트: 봄 벚꽃, 여름 바다, 가을 단풍, 겨울 눈꽃, 크리스마스, 우주 탐험, 레트로 70. 테마마다 배경, 교실, 급식실, 도서관, 과학실, 운동장을 따로 사요. 여섯 개를 모두 모으면 세트마다 수업료가 5% 올라요
- 뽑기 없이 정해진 값으로만 팔아요.
