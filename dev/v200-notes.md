# 2.0.0 중학교 작업 메모

브랜치 `feat/v200-middle`. 1.8.0(`feat/v180-merge`) 위에 만들었어요. 설계는 Claude Docs '2.0.0 중학교 설계안'(지섭 결정), 그림은 작업지시서 19(art/v200, 지도 6장 다시 그리는 중)와 20(art/v201, 복도와 새 학생 6종). 버전 번호와 패치노트는 "업데이트하자" 때 올려요.

## 그림 없이 먼저 만든 것 (2026-10-27)

- 학교급 셋: `TIER_OPEN = 3`, `TIERS`에 고등학교(아직 닫힘)와 `newb`(새 건물 이름). `geoIdx(t)`, `geo(t)`가 학교급마다 지도(`GEO[2]` 중학교, 2026-10-27 다시 그린 지도 6장과 lots_middle.md 좌표, 기숙사 공사 자리 이름표는 간판과 겹치지 않게 위로 `nextTagY`). `#mapImg2`, 지도 class `g-0/1/2`, `tier-2`(매점 보이기). `ART_FB`가 없는 그림 대신 쓸 그림(`bld_store_on` → 급식실 등). 장식 자리 `DECO_SLOTS[2]`, `DECO_SIGN[2]`
- 수업료와 공사비 배수 표 `TIER_SCALE = { inc: [1, 1e3, 1e6], cost: [1, 2e3, 5e8] }`. 중학교 공사비 5억 배는 균형 제안서(2.0.0) 제안값(예전 규칙이면 400만 배)
- 매점 `FAC.store`(tier 2, 레벨마다 수업료 +15%(`per`), 값 `60 × 1.8^L`), 가구 4종 `FUR.store`(간식 진열대, 음료 냉장고, 계산대, 간식 탁자), 방 그림이 없으면 `FUR_ROOM.store`(임시 그림), 지도 `#b-store`, 지붕 필터 `#rt-store`
- 학생 명부 `S.roster = { list: [{ sp, nm, a: [과학, 운동, 독서, 미술] 1~100, c: 동아리(-1 없음), cw: 동아리에 든 주 }], wk, gen }`. 중학교부터(`ROSTER_TIER`), 처음 12명(만난 친구에서 겹치지 않게, 방금 전학 온 친구 포함), 중학교에서 전학 온 친구는 끝에 더해서 16명까지. 동물마다 잘하는 능력 `SP_ABIL`. 별 `star(v) = ceil(v/20)`
- 동아리 `CLUBS`(과학부 수업료, 운동부 학교 행사 보상, 독서부 수업료, 미술부 장식 값 할인). 보너스 `clubPct(c) = min(30, 2 × 부원 셋의 맞는 능력치 별 합)`, 미술부 할인은 절반. `clubTuitionMult()`는 `tuitionMult()`에, `clubFestMult()`는 `festPrize`, `sportsPrize`에, `clubDecoOff()`는 `decoCost`에 들어가요. 자동 추천 `clubAuto()`는 셈으로 가장 큰 별 합(동아리마다 3자리). 바꾸기 `clubSet(i, c)`(꽉 차면 가장 약한 부원과 맞바꿈)
- 능력치가 자라는 법: 그 동아리 건물을 한 레벨 올리면 부원 +1(`clubFacUp`, 과학실, 운동장, 도서관, 교실), 한 주(게임 시계)가 지나면 그 주 내내 같은 동아리였던 부원 +5 + 건물 레벨 10마다 +1(`clubWeekTick`, 8주까지), 발표회 +5
- 발표회 `clubShowGo(c)`: 부원 능력치 +5, 수업료 30분치, `S.club = { last: 게임 날짜, n, shown: [4] }`. 주기 `CLUB.showDays`(제안값 1일, 설계안은 7일)
- 학교 복도 `#panelHall`(상점 거리와 같은 틀, 그림이 오면 `hall_bg`, `hall_*` 문 그림. 지금은 문 모양 임시 그림). 들어가는 단추 `#btnHall`(홈 왼쪽 학교 행사 아래, 중학교부터). 동아리실 `#panelClub`, 자리 고르기 창 `#mSeat`
- 졸업식 사진 `S.snap[학교급] = { f, bs, st, at, roster }`(promote 때 `snapTake()`). 학교급 모습 보기: 홈 아래 왼쪽 동그라미 6개 `#tierDots`(초등학교부터), 지난 학교급 `#tierView`(보기 전용 svg, 사진이 없으면 모두 지어진 모습 `snapOf`), 꾸미기는 그 지도 자리에(`viewMap()`)
- 전학생 12종(`NEWCOMERS` 끝에 햄스터, 오리, 거북, 두더지, 개구리, 고라니). 옛 저장의 전학생 채우기는 6종까지만(`NEWCOMERS_OLD`). 친구 성장 쪽지는 이미 쓰던 학교도 계속(`growOn()`). 그림이 오기 전에는 그림 문자(`KID_EMOJI`)
- 전학 대화 `#mTalk`(`showNewTalk`, `NEW_TALK` 대사): 종업식과 졸업식 창 다음에 교감 소개, 자기소개 두 줄, 마지막 안내
- 메인 퀘스트: 중학교 12~15장(`j1`~`j29`, `h2` 침입자, `yt: 2`로 중학교 학년 문), 초등학교 장 보강 11개(`e44`~`e54`), 초등학교 졸업식 `e39`(6학년 장을 마쳐야 졸업식이 열려요 `promoteLocked()`), `q26` 이름. 새 퀘스트 종류 `club`, `shows`(지금까지 연 횟수), `clubSum`, `star`, `clubShown`, `fpUp`(이 학교급에서 장학재단을 고친 횟수, `S.tfp`). 장마다 학교급 `chTier(ch)`
