# 1.7.0 동물 도감, 이벤트 작업 메모

브랜치 `feat/v170-dex-event`. 1.6.0(`feat/v160-puzzle`) 뒤에 합쳐요. 버전 번호와 패치노트는 낼 때 따로 올려요.

## 정한 것

- 공용 함수 이름: `trustedNow()`(밀리초 숫자), `trustedDay()`('YYYY-MM-DD', 한국 시간 자정 기준). 1.6.0이 진짜 함수(가장 늦게 본 시각 저장, 시간이 뒤로 가면 날짜 안 넘기기)를 만들고, 1.7.0은 그 둘만 써요. 지금은 1.7.0 구역 맨 위에 **임시 함수**(기기 시간만 돌려주고 저장 칸 없음)가 있어요. 1.6.0이 합쳐지면 그 두 줄만 지워요.
- 분치 보정 공용 함수 `tierMinutes(m)` = 분치 × 2^학교급(유치원 1배, 초등 2배, 중학교 4배). 도토리 양은 `minAcorns(m)`. 1.7.0 보상에만 쓰고 기존 퀘스트, 행사, 출석 보상은 그대로예요.
- 그림: 1.7.0 전용 묶음 `window.FS_IMG170`(FS_IMG 바로 뒤, 지금은 비어 있음). `IMG7(열쇠)`가 170 묶음 → 기존 FS_IMG → 임시 도형(`PLACE170`) 순서로 찾아요. 넣는 법: `cd dev && python3 embed_assets.py --block 170 ../art/v170/dex ../art/v170/event`.
- 도감: 학생 11종(기본 5 + 전학생 6) + 선생님 3명(다람쥐, 부엉이, 곰) + 특별 손님 ??? 4칸(뱀, 매, 까치, 졸업생) + 앞으로 올 친구 ??? 3칸. 고슴도치 선생님은 보류(칸 없음). 친밀도는 1.9.0으로.
  - 등록: 그 종의 학생이 지도에 처음 나타나면(`addKid` 한 줄), 선생님은 모시면(1초 갱신에서 `S.t` 확인). 종업식을 열었으면 기본 5종은 모두 등록.
  - 보상: 등록 1종마다 황금 도토리 1개. 학생 5종 수업료 30분치, 학생 11종 황금 3개, 14종 모두 황금 5개와 기념 그림. 도감을 열 때 받지 않은 것을 "도감 선물" 창 하나로 묶어 받고, `dex.paid`에 적어 두 번 받지 않아요.
  - 옛 저장(dex 칸 없음): 기본 5종, 전학생 `p.species`만큼, 모신 선생님을 `sanitize170()`이 채워요. 선물은 처음 열 때 한꺼번에(최대 황금 도토리 22개: 등록 14 + 학생 11종 3 + 도감 완성 5, 그리고 학생 5종 수업료 30분치).
- 이벤트: 달력 규칙(매달 1~7일 도토리 수확 축제, 15~21일 숲속 친구 주간, `EV_MONTHLY`) + 특별 이벤트 표(`EV_SPECIAL`: 설날, 어린이날, 추석, 크리스마스 자리. `start`, `end`를 'YYYY-MM-DD'로 적으면 열리고 반복 이벤트보다 먼저예요. 지금은 비어 있어요).
  - 출석 도장 7개: `trustedDay()` 날짜 기준 하루 한 번. 1, 2, 4, 6, 7개째 수업료 10분치, 3개째 10분치와 황금 1개, **5개째 60분치와 황금 3개(큰 보상)**. 7일 중 이틀 빠져도 완성.
  - 미션 3개: 달마다 바뀌는 표 `EV_MONTHS`(종류, 목표, 분치, 황금). 기존 횟수 통계 `S.st`의 "이벤트 시작 때와의 차이"로 재요. 아직 못 하는 종류(`ok()`가 거짓: 운동회는 행사가 열렸을 때, 체험학습은 열렸을 때, 줍기와 흔들기와 오늘의 미션 끝내기는 놀이터가 있을 때, 연수는 연수할 선생님이 있을 때)는 `EV_FALLBACK`(흔들기, 줍기, 고치기, 자리 비운 도토리 받기, 연수 순서. 할 수 있고 겹치지 않는 것만)으로 바꿔 넣어요. 놀이터가 없으면 참나무를 눌러도 안내만 나오고 흔들기 횟수가 안 올라가요. 오늘의 미션은 줍기와 흔들기가 섞여 나와서 놀이터 없이는 하루 1개만 끝낼 수 있는 날이 있어 이벤트 목표(6~9개)를 못 채울 수 있어요. 고치기, 자리 비운 도토리 받기(30초 넘게 닫았다 열기), 연수(다람쥐 선생님은 처음부터 Lv.1이고 최고 레벨이 없어요)는 새 학교도 늘 할 수 있어서 미션 3개가 언제나 채워져요. 드물게 그 학년 시설과 가구를 모두 최고로 올린 학교는 종업식 전까지 고치기를 못 해요(기존 구조라 그대로 둬요). 셋 다 하면 기념 상자(황금 2개, 수료증 1장, `EV_BOX`).
  - 특별 이벤트가 그달 반복 이벤트 기간과 하루라도 겹치면 그달 그 반복 이벤트는 아예 건너뛰어요(`evSpecialHits`). 도장과 미션이 끊기거나 반복 이벤트가 0부터 다시 열려 도장을 또 받는 일이 없어요. 다음 이벤트 안내(`evNext`)도 같은 규칙이에요. 쉬는 기간(그달 반복 이벤트 날짜)에는 이벤트 화면 맨 위에 "이번 달은 ○○ 때문에 도토리 수확 축제는 쉬어요" 한 줄을 보여 줘요(`evSkipped`, 특별 이벤트 중에도 보여요).
  - 회차: `ev.cur`가 'harvest:2026-11'처럼 달마다 다른 글자라서 달이 바뀌면 도장과 미션이 새로 시작해요. 이벤트가 없으면 다음 이벤트 안내.
- 시간 속이기: 1.6.0 공용 함수에 맡겨요. 앞으로 돌려 미리 여는 건 막지 않아요. 보상은 작고 랭킹(학교 파워)에 영향 없어요.

## 저장 칸 (새 칸만, 기존 칸 그대로)

```
dex: { got: { rabbit: 1761000000000, tea_owl: ... },   // 종마다 등록한 시각. 선생님은 tea_ 앞붙이
       paid: ['rabbit', 's5', ...] }                    // 받은 선물(등록 보상과 s5, s11, s14)
ev:  { cur: 'harvest:2026-11', start: 0,               // 지금 회차와 시작 시각
       stamp: { n: 0, last: '2026-11-03' },             // 도장 수와 마지막 받은 날
       list: [{ t: 'picks', n: 150, b: 0, m: 15, g: 1, done: false }],   // 미션 3개(기준값 b)
       box: false }                                     // 기념 상자 받았는지
```
서버 규칙(`database.rules.json`)은 바꾸지 않았어요.

## 시험 (`dev/s48test.py`)

- 기기 시간은 `Date.now`를 바꿔 흉내 내고, **날짜는 앞으로만 돌려요**(11월 3일 → 4일 → 7일 → 10일 → 16일 → 12월 2일 → 6일 → 8일 → 25일). 1.6.0 공용 시계 `gameNow()`, `gameToday()`는 시간이 뒤로 가면 막기 때문에, 합친 뒤에도 그대로 통과해요.
- 날짜를 뒤로 돌리는 검사를 더하고 싶으면 그 사이에 `S.clk`(1.6.0이 가장 늦게 본 시각을 적는 저장 칸)를 비우고 돌려요. 예: `F.S.clk = ...기본값...` 뒤에 `set_day()`.
- 1.6.0 쪽 시험 이름이 `s46test.py`라서 1.7.0 시험은 `s48test.py`예요.
- 새 저장(놀이터 없음)으로 이벤트를 열어 모든 달의 반복 이벤트 두 개와 특별 이벤트 표의 미션이 이룰 수 있는 종류(고치기, 자리 비운 도토리 받기, 연수)이고 겹치지 않는지 봐요.

## 합칠 때 할 일 (1.6.0이 main에 들어간 뒤)

1. 이 브랜치를 1.6.0이 합쳐진 `main` 위로 옮겨요. 충돌이 나는 `fresh()`, `sanitize()`, `window.__forest` 줄은 **1.6.0과 1.7.0 둘 다 살려요**(각자 더한 한두 줄을 모두 남겨요). `setTab()`과 홈 오른쪽 버튼(정수 상점 버튼 바로 위)도 같아요.
2. 1.7.0 구역 맨 위의 임시 `trustedNow`, `trustedDay` 두 줄을 지우고, 1.7.0 구역 안의 `trustedNow(` → `gameNow(`, `trustedDay(` → `gameToday(`로 바꿔요(1.7.0 구역 안에서만 바꾸면 돼요. `s48test.py`의 `F.trustedDay()`와 `__forest`의 손잡이 이름도 같이).
3. `index.html`은 손으로 고치지 말고 `python3 dev/build_gh.py .`로 다시 만들어요.
4. `.dex-card.new::after`의 'NEW' 배지를 1.6.0 `fx_sparkle` 그림으로 바꿔요.
5. `cd dev && python3 wrap.py && python3 s48test.py && python3 s37test.py`로 확인해요.
