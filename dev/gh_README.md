# 숲속 동물 학교 테스트판

도토리를 모아 숲속 학교를 키우는 방치형 게임이에요. 토스 미니앱으로 내기 전에 몇 명이 먼저 해 보면서 속도와 재미를 확인하려고 GitHub Pages에 올렸어요.

- 게임 주소: https://seop-sci.github.io/forest-school/
- 저장: Firebase 실시간 데이터베이스 (테스터마다 따로 저장돼요)

## 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 게임 전체예요 |
| `config.js` | Firebase 연결 설정이에요. 비어 있으면(null) 이 기기에만 저장하는 체험판으로 열려요 |
| `database.rules.json` | 데이터베이스 규칙이에요. Firebase 콘솔의 규칙 탭에 붙여 넣어요 |
| `og.png` | 카카오톡에 링크를 보낼 때 보이는 미리보기 그림이에요 |

## 처음 한 번 설정하기

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에서 **프로젝트 추가**를 눌러요.
2. 이름은 `forest-school`처럼 적어요. Google 애널리틱스는 꺼도 돼요.

생태계 게임(eco-battle) 프로젝트와 따로 만들면 수업에 쓰는 규칙과 섞이지 않아요.

### 2. 실시간 데이터베이스 만들기
1. 왼쪽 메뉴 **빌드 > Realtime Database > 데이터베이스 만들기**
2. 위치는 **싱가포르(asia-southeast1)**, 보안 규칙은 **잠금 모드로 시작**을 골라요.
3. **규칙** 탭에서 원래 글을 모두 지우고 `database.rules.json` 내용을 붙여 넣은 뒤 **게시**를 눌러요.

### 3. 익명 로그인 켜기
**빌드 > Authentication > 시작하기 > 로그인 방법 > 익명 > 사용 설정 > 저장**

테스터는 회원가입 없이 바로 시작하고, 기기마다 익명 id가 하나씩 생겨요.

### 4. 웹 앱 등록하고 config.js 채우기
1. 왼쪽 위 톱니바퀴 > **프로젝트 설정 > 일반 > 내 앱**에서 웹(`</>`) 아이콘을 눌러요.
2. 앱 이름을 적고 등록하면 `firebaseConfig`가 보여요.
3. 그 안의 값을 `config.js`의 `null` 자리에 옮겨 적어요. `databaseURL` 줄이 꼭 있어야 해요. 없으면 2번을 마친 뒤 프로젝트 설정 화면을 다시 열어 복사해요.

### 5. GitHub Pages 켜기
저장소 **Settings > Pages > Build and deployment**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 눌러요. 1~2분 뒤 게임 주소가 열려요.

### 6. 잘 붙었는지 보기
게임의 **설정 > 정보 > 저장 위치**에 `서버 (방금 저장)`처럼 보이면 성공이에요. 문제가 있으면 그 자리에 까닭이 나와요.

| 저장 위치에 보이는 말 | 고칠 곳 |
| --- | --- |
| 서버를 연결하기 전 체험판 | `config.js`가 아직 null이에요 |
| Firebase에서 익명 로그인을 켜 주세요 | 3번 |
| 데이터베이스 규칙을 확인해 주세요 | 2번의 규칙 |
| config.js에 databaseURL이 없어요 | 4번 |
| config.js의 Firebase 설정을 확인해 주세요 | 4번에서 값을 잘못 옮겼어요 |

## 테스트 현황 보기
설정 탭 맨 아래 **버전** 줄을 빠르게 다섯 번 누르면 개발자 메뉴가 열려요. **황금 도토리 100개 받기**로 상점을, **체험학습 바로 돌아오기**로 체험학습을 시험해 볼 수 있고, **테스트 현황 보기**에서 테스터마다 어디까지 했는지(학교, 학년, 퀘스트), 얼마나 했는지(플레이 시간, 접속 횟수, 출석, 광고), 마지막으로 언제 들어왔는지 볼 수 있어요.

같은 기록이 Firebase 콘솔의 Realtime Database 데이터 탭 `forest/stats` 아래에도 있어요.

메인 퀘스트 3장을 마치면 교장 선생님 이름(닉네임)을 정하는 창이 떠서 랭킹에 바로 올라가요. 처음은 무료, 그다음부터 바꿀 때마다 황금 도토리 50개, 60개, 70개...가 들어요. 주사위 버튼은 랭킹에 없는 귀여운 이름을 골라 줘요. 랭킹에 이름을 올린 테스터는 그 이름으로 보이고, 아니면 `이름 없는 학교 #K7QM`처럼 학교 번호로 보여요. 학교 번호는 게임의 설정 > 정보에서 볼 수 있어요.

## 다른 기기에서 이어하기
카카오톡 안에서 열던 게임을 사파리나 크롬으로 옮기거나 휴대폰을 바꿀 때 써요.

1. 원래 기기: **설정 > 다른 기기에서 이어하기 > 코드 만들기**
2. 새 기기: 게임을 열고 같은 메뉴에 코드를 넣어요. 원래 기기에서 **이어하기 링크 복사**를 눌러 링크를 보내면 코드를 넣지 않아도 돼요.

코드는 30분 동안 한 번만 쓸 수 있어요.

## 서버에 저장되는 것

| 자리 | 내용 | 볼 수 있는 사람 |
| --- | --- | --- |
| `forest/saves/<id>` | 게임 저장 | 본인만 |
| `forest/rank/<id>` | 랭킹 이름, 학교 점수 | 게임을 연 사람 모두 |
| `forest/stats/<id>` | 진행 단계, 플레이 시간, 접속 횟수 같은 테스트 기록 | 게임을 연 사람 모두 |
| `forest/moves/<코드>` | 다른 기기로 옮기는 학교 (30분) | 코드를 아는 사람 |

이름이나 연락처 같은 개인 정보는 받지 않아요. 랭킹 이름은 테스터가 직접 정해요. `config.js`의 값은 공개돼도 괜찮고, 데이터는 규칙이 지켜요.

## 비용
Firebase 무료 요금제(Spark)로 충분해요. 테스터 몇 명이면 저장 공간 1GB, 한 달 다운로드 10GB 한도에 한참 못 미쳐요.

## 기록 지우기
- 한 사람: Firebase 콘솔 데이터 탭에서 `forest/saves`, `forest/rank`, `forest/stats` 아래 그 사람의 id를 지워요.
- 모두: `forest`를 통째로 지워요. 테스터 기기에 남은 저장은 다음에 열 때 다시 서버로 올라가요.
- 테스터가 처음부터 하고 싶을 때: 게임의 **설정 > 처음부터 다시**

## 게임을 고칠 때
게임은 Claude 화면의 시제품과 같은 코드예요. 고칠 때는 `index.html`만 새로 만들어 올리고 `config.js`는 그대로 둬요.

## 황금 도토리와 꾸미기 상점
아래 **상점** 탭에서 열어요. 구글 계정을 처음 연결하면 수료증 15장, 기금 3, 황금 도토리 30개를 선물로 줘요.
- 모으는 곳: 조금 어려운 퀘스트 2개 (퀘스트 카드에 황금 도토리가 보여요), 광고를 끝까지 보면 1개 (하루 10개까지), 상점에서 광고 보고 2개 (하루 5번), 출석 도장 1개 (7일째 5개), 메인 퀘스트 한 장 3개, 종업식 2개, 졸업식 10개
- 쓰는 곳: 테마 세트, 학생 모자와 목 장식, 부스터(1회 사용 가능: 특식 데이 10분, 30분 건너뛰기, 도토리 자동 줍기 10분)
- 테마 세트: 봄 벚꽃, 여름 바다, 가을 단풍, 겨울 눈꽃, 크리스마스, 우주 탐험, 레트로 70. 테마마다 배경, 교실, 급식실, 도서관, 과학실, 운동장을 따로 사거나, 남은 칸을 한 번에 살 수 있어요 (두 칸 넘게 남았으면 10% 할인). 산 테마는 **이 테마로 한 번에 바꾸기**로 학교 전체를 한 번에 바꿔요. 여섯 개를 모두 모으면 세트 값에 맞춰 수업료가 올라요 (봄, 여름, 가을 +19%, 겨울 +23%, 크리스마스와 레트로 +26%, 우주 +30%). 배경을 사면 바깥 색과 칠판 색도 그 테마로 바뀌어요
- 뽑기 없이 정해진 값으로만 팔아요.

## 시설 안 가구
시설을 누르면 안이 보여요. 시설마다 가구가 네 개 있어요.
- 교실: 책상, 의자, 선풍기, 청소도구함 / 급식실: 식탁, 배식대, 정수기, 식판 선반 / 도서관: 책장, 열람 책상, 독서 소파, 스탠드 / 놀이터(운동장): 미끄럼틀, 그네, 철봉, 벤치 / 과학실: 실험대, 현미경, 약품장, 지구본
- 가구는 건물 레벨까지 올릴 수 있고, 네 개가 모두 건물 레벨에 닿아야 건물을 한 단계 키울 수 있어요.
- 가구값은 건물값과 따로 내요. 네 개를 합치면 다음 건물값의 60%예요. 가구는 따로 효과가 없어요.
- 가구 모습은 Lv.1 낡은, Lv.5 튼튼한, Lv.10 산뜻한, Lv.15 반짝이는 모습으로 바뀌어요.
- **가구 모두 한 레벨씩 올리기**로 덜 찬 가구를 한 번에 1레벨씩 올려요.
- 가구가 생기기 전에 하던 학교는 가구가 지금 건물 레벨까지 채워져 있어요.

## 학생이 말을 걸어요
25~45초마다 학생 한 명 머리 위에 느낌표가 떠요(20초 동안). 누르면 학생이 한마디 하고 떨어진 도토리 두 개 값만큼 도토리를 줘요. 학교 행사 중이나 다른 창이 열려 있을 때는 뜨지 않아요.

## 튜토리얼
처음 시작한 학교에는 고슴도치 교감 선생님이 칠판, 퀘스트, 건물(안의 가구), 참나무, 지도 왼쪽 버튼, 아래 탭을 차례로 비추며 안내해요(8단계). 끝까지 보면 황금 도토리 10개. **나중에**를 누르면 다음에 열 때 다시 물어보고 설정에서 이어 볼 수 있어요. **건너뛰기**는 한 번 더 확인하고, 건너뛰면 보상은 없어요.

## 오늘의 미션과 주간 리그
- 이번 주 미션: 월요일마다 4개(도토리 150개 줍기, 학교 행사 5번처럼 크게 하는 일). 하나에 황금 도토리 3개.
- 미션 포인트: 오늘의 미션 20점, 보너스 상자 40점, 이번 주 미션 50점. 일주일 동안 모아서 100, 250, 450, 650, 850점 상자를 차례로 열어요. 마지막 상자는 처음 한 번 주간 보상으로만 받는 금빛 왕관을 줘요(그다음부터는 황금 도토리).
- 학교 행사와 운동회는 피버 타임으로 보여요: 3, 2, 1 카운트다운, 금빛으로 반짝이는 지도와 색종이, 화면 위에 고정된 점수판, 콤보, 끝날 때 '끝!' 배너.
- 오늘의 미션: 퀘스트 탭 맨 위에 하루 3개가 나와요(자정에 바뀌어요). 하나에 황금 도토리 1개와 수업료 5분치, 셋 다 하면 보너스 상자(황금 도토리 3개, 수료증 1장).
- 주간 리그: 랭킹 탭의 **주간 리그**에서 이번 주 리그 점수로 겨뤄요. 월요일마다 새로 시작해요. 미션 10점, 보너스 상자 20점, 학교 행사 성공 15점(실패 5점), 체험학습 10점(1시간마다 +5), 종업식 20점, 퀘스트 3점. 학교 크기와 상관없는 점수라서 새로 온 학교도 겨룰 수 있어요.
- 지난주 순위 보상: 1위 황금 도토리 30개, 2~3위 20개, 10위 안 10개, 참여만 해도 3개 (마지막으로 본 순위로 줘요).
- 리그 점수는 랭킹 문서(`forest/rank/<id>`)의 `ws`, `lp`, `week`에 함께 올라가요. 데이터베이스 규칙은 바꾸지 않아도 돼요.

## 종업식과 레벨 확장
- 종업식을 열어도 시설, 선생님, 도토리, 학생은 그대로 남아요. 대신 학년(해)마다 시설의 최고 레벨이 5씩 늘어요. 유치원은 Lv.16부터(2년째 Lv.21), 초등학교는 Lv.18부터(2학년 23, 3학년 28, 4학년 33, 5학년 38, 6학년 43).
- 동네(마을 → 대도시)는 해마다 다시 키우고, 필요한 평판은 해마다 20%씩 높아져요. 그래서 늘어난 레벨까지 키워야 대도시가 돼요.
- 높은 레벨은 값이 덜 가파르게 올라요 (시설은 Lv.15, 선생님은 Lv.12부터 한 레벨에 1.35배).
- 명예 교장실의 새 학기 준비물은 종업식마다 수업료 30분치씩 선물로 바뀌었어요.
- 졸업식(유치원 → 초등학교)만 학교를 통째로 옮기면서 처음부터 시작해요.
- 종업식 화면에 그 해의 시설 레벨과 학생 수 기록이 나와요.

## 초등학교 학년별 퀘스트와 현장체험학습
- 초등학교 2학년부터 6학년까지 학년마다 메인 퀘스트가 한 장씩 있어요 (7장 새 친구들, 8장 현장체험학습, 9장 숲속 운동회, 10장 학예회, 11장 졸업 여행). 그 장의 퀘스트를 마쳐야 그 학년 종업식을 열 수 있어요.
- 현장체험학습은 3학년부터 열려요. 지도 왼쪽의 버스를 눌러 뒷산(30분), 시냇가(1시간), 박물관(2시간), 바닷가(4시간), 별빛 천문대(8시간)로 보내요. 실제 시간이 흐르는 동안 학교는 그대로 돌아가요.
- 돌아오면 도토리, 수료증, 먼 곳은 황금 도토리, 그리고 그곳 기념품 하나를 가져와요. 기념품은 하나에 수업료 +2%, 한 곳 세 가지를 다 모으면 +10% 더 올라요. 졸업해도 남아요.
- 광고를 보면 다녀오는 시간을 줄이거나(전체의 1/4, 적어도 15분) 돌아왔을 때 도토리와 수료증을 2배로 받아요.
- 떠날 때는 노란 버스가 교문으로 들어와 학생 몇 명을 태우고 나가고, 돌아오면 학생들이 내려요. 다녀오는 동안 그 학생들은 지도에서 빠져요.
- 학교 행사: 지도 왼쪽 **학교 행사** 버튼에서 학년마다 열리는 행사를 골라요. 행사마다 2시간에 한 번, 광고를 보면 바로 다시 열 수 있어요. 성공하면 수업료 6분치와 황금 도토리 1개, 실패하면 3분치를 받고, 행사 동안에는 그 행사 곡이 나와요.
  - 1학년 봄 소풍 보물찾기: 나무 사이에 숨은 쪽지를 30초 안에 12장
  - 2학년 새 친구 환영회: 광장에 둥글게 모여 날아오르는 풍선 15개 터뜨리기
  - 5학년 학예회: 광장 무대에 친구들이 차례로 올라가고, 떠오르는 음표 18개에 박수
  - 6학년 졸업 사진 찍기: 교실 앞에 두 줄로 서서 머리 위 웃음 별 14개를 누르면 찰칵
- 4학년 숲속 운동회: 40초 동안 학생들이 청팀과 백팀 머리띠를 두르고 트랙을 달리고, 굴러오는 공을 주울 때마다 청팀이 1점이에요. 이기면 상품(수업료 6분치)과 황금 도토리 1개, 지면 절반을 받아요.

## 배경음악
음악 파일 없이 게임 안에서 직접 연주해요. 모두 이 게임을 위해 새로 쓴 곡이에요. 학교 탭은 배경 테마마다 곡이 바뀌고(기본, 봄, 여름, 가을, 겨울, 크리스마스, 우주, 레트로), 퀘스트, 선생님, 졸업, 상점, 랭킹, 설정 탭은 탭마다 곡이 따로 있어요. 상점의 테마 카드에서 **테마 곡 듣기**로 미리 들어 볼 수 있고, 설정에서 배경음악과 효과음을 따로 끌 수 있어요.
