# 1.8.0 숲속 합치기(머지 게임) 작업 메모

브랜치 `feat/v180-merge`. 1.7.0(`0b24045`) 뒤에 만들었어요. 설계는 프로젝트 문서 "머지 게임 설계안 (1.8.0)", 그림은 "Codex 작업지시서 13". 버전 번호와 패치노트는 낼 때 따로 올려요.

## 정한 것

- 자리: 미니게임 탭의 두 번째 카드 "숲속 합치기"(`#mgOpen`). 블록 퍼즐처럼 화면 전체를 덮는 장면 `#mgScene`(`.pz .mg`)이고 `.pz` 틀(배경, 뒤로 단추, 시트)을 같이 써요. 코드는 "1.8.0 숲속 합치기 BEGIN/END" 표시 안(CSS, HTML, JS 각각)에 있어요.
- 판: 가로 8 × 세로 10 = 80칸. 저장은 `S.mg.board` 한 줄 글자(칸마다 2글자: `..` 빈칸, `a1`~`ax` 조각(종류 글자 + 단계 1~9, x=10), `A1`~`A5` 생산기(대문자 + 레벨)). `mgCells()`/`mgSetCells()`로 읽고 써요.
- 종류 8개 = 생산기 4개 × 2종류. 참나무 A(도토리 a, 버섯 m), 급식 냄비 F(급식 f, 음료 d), 문구함 S(학용품 s, 미술용품 c), 화분 G(꽃 g, 채소 v). 생산기는 처음에 0, 2, 5, 7칸(`MG.genAt`)에 놓이고 옮길 수 있어요. 생산기끼리는 합쳐지지 않고 자리만 바꿔요.
- 생산기 누르기: 에너지 1, 가장 가까운 빈칸에 조각 하나. 두 종류가 번갈아 나오되 같은 종류 세 번 연속은 안 나와요(`S.mg.last`, `lastN`). 판이 가득 차면 에너지를 안 써요.
- 생산기 레벨표 `MG.LV`(Lv.1 100 / Lv.2 95, 5 / Lv.3 90, 8, 2 / Lv.4 85, 11, 3.5, 0.5 / Lv.5 80, 14, 5, 1). 강화 조각(`S.mg.up`) 값 `MG.UPCOST` = Lv.2 1, Lv.3 1, Lv.4 2, Lv.5 2. Lv.5가 최고.
- 에너지 `S.mg.e`: 최고 100(`MG.EMAX`), 1분에 1 회복(`mgTick`, 게임 시계 `gameNow()` 기준이라 시계를 되돌려도 안 늘어요), 보상으로 100을 넘길 수 있고(최대 999) 넘은 동안은 회복하지 않아요. 광고 하루 2번 +50(`S.mg.ad`, 날짜는 `gameToday()`).
- 에너지 보상(`MG.E`): 오늘의 미션 하나 15, 보너스 상자 20, 이번 주 미션 하나 30, 출석 도장 10(5개째 30), 기념 상자 50. 강화 조각: 기념 상자, 주간 마지막 상자, 도장 7개째, 8단계 이상 주문.
- 합치기: 같은 종류 같은 단계 둘을 겹치면 다음 단계(10단계가 최고, 10단계끼리는 자리 바꾸기). 다른 것 위에 놓으면 자리 바꾸기, 빈칸이면 옮기기. 놓는 칸 둘레(상하좌우)에 같은 조각이 3개 더 있으면 다섯을 한 번에 합쳐 다음 단계 2개 + 1단계 1개(5개 보너스).
- 조각 값: 에너지 환산 `mgEnergyOf(n) = 2^(n-1)`. 팔기는 에너지 × 0.1분치, 주문은 에너지 × 개수 × 0.2분치. 도토리는 `minAcorns()`(수업료 분치, `tierMinutes`로 학교급 보정)이라 상한이 있어요(10단계 1개 주문 = 102.4분치).
- 학생 주문 3개(`S.mg.orders`, 주문마다 `it: [{k, n, c}]` 1~2개): 절반(`MG.MIXED`)은 두 종류를 섞은 주문(각 1개), 나머지는 한 종류(3단계 이하면 40%로 2개). 다른 주문에 있는 종류는 되도록 피하고, 단계는 그 종류 최고 단계(`S.mg.best`) −2~최고(최소 2). 옛 모양 `{k, n, c}` 주문도 `sanitize180`이 읽어요. 장식 조각(`S.mg.pieces`) 6단계 1, 8단계 2, 10단계 3(개수만큼). 8단계 이상은 강화 조각 1. 주문 바꾸기는 30분에 한 번(`S.mg.swapAt`).
- 장식 조각은 1.8.x(앨범, 스티커판)에서 쓰려고 모아 두기만 해요. 지금은 위쪽 줄에 개수만 보여요.
- 메인 퀘스트 2장(p2 뒤): `m1` 숲속 합치기 3단계 만들기(`mgBest`, 700), `m2` 학생 주문 3개 채우기(`mgOrders`, 800). `S.mg.st`에 merges, orders, ups, taps 횟수.
- 저장: `fresh()`의 `mg: mgFresh()`, `sanitize180(d, s)`가 옛 저장(mg 없음 → 에너지 100과 빈 판), 망가진 판(글자 수나 모르는 글자 → 빈 판), 빠진 생산기(종류마다 하나 되살림, 둘 이상이면 하나만)를 바로잡아요.
- 그림: 전용 묶음 `window.FS_IMG180`(FS_IMG170 뒤 표시 사이, 지금은 비어 있음). `IMG180(열쇠)`가 없으면 색 조각과 그림 문자로 보여요. 열쇠: 조각 `mg_a_01`~`mg_v_10`, 생산기 `mg_gen_A`(대문자), 화면 `mg_board`, `mg_ic_energy/piece/up`, `mg_order_light/dark`(주문 쪽지 틀), `mg_card`, `mg_help_1~3`. 배경은 블록 퍼즐 `pz_bg`를 같이 써요. 넣는 법: `cd dev && python3 embed_assets.py --block 180 ../art/v180/items ../art/v180/ui`.
- 시험 손잡이(`window.__forest`): `MG`, `mgCells`, `mgSetCells`, `mgTick`, `mgAddEnergy`, `mgAddUp`, `mgTapGen`, `mgDrop`, `mgSell`, `mgUpgrade`, `mgClaimOrder`, `mgSwapOrder`, `mgOrderOk`, `mgFillOrders`, `mgOpen`, `mgClose`, `mgRenderAll`, `mgSpawnLevel`, `mgNearestEmpty`, `mgEmptyBoard`, `mgOrderReward`, `mgUI`, `sanitize180`, `mgWatchAd`. 시험은 `dev/s57test.py`. 퀘스트 봇(`qbot.py`)은 `mgBest`, `mgOrders` 퀘스트를 통계로 바로 채워요.

- 손맛: 생산기를 누르면 조각이 생산기에서 빈칸으로 포물선을 그리며 날아가 내려앉아요(`mgFly`, `.mg-fly`, 도착 칸은 `.hide`였다가 `.land`). 생산기는 눌리는 모양(`.press`), 합치면 조각 색 가루가 터지고(`mgDust`) 판이 살짝 울리고(`.thump`) "n단계!" 글자가 떠요. 에너지, 조각 숫자는 바뀔 때 튀어요(`.bump`). 움직임 줄이기(`rt.reduced`)면 모두 건너뛰어요.
- 숲속 퍼즐(옛 이름 블록 퍼즐)도 같이 손봤어요: 콤보는 줄을 못 지운 놓기가 4번(`PZ.comboGrace`) 이어져야 끊겨요(`cur.miss`, 저장에 포함). 점수 칸 아래에 "콤보 ×1.5 (3번 안에 지우기)" 표시. 빈칸은 파인 느낌, 블록은 밝은 테두리와 그림자(`.pz-cell.on`). 미니게임 탭 이름은 "숲속 퍼즐", "숲속 대결"(준비 중).

- 힌트: 7초(`MG.HINT_AFTER`) 동안 아무것도 안 하면 손가락(👆)이 알려 줘요(`mgHintPick`): 건넬 수 있는 주문 카드 → 합칠 수 있는 짝(주문 조각 바로 아래 단계 먼저, 그다음 높은 단계) → 주문 종류가 나오는 생산기(에너지와 빈칸이 있을 때). 3초 뒤 사라지고, 누르면 바로 지워져요(`mgTouch`). 안내 시트, 강화 시트, 보상 창이 열려 있으면 안 나와요.

- 그림 94장(작업지시서 13) 중 92장을 넣었어요(805KB). 판 그림(800×1000)은 칸 자리가 가로 47~751, 세로 59~939, 한 칸 88이라 `.mg-board.has-art`의 여백을 거기에 맞췄어요. 주문 쪽지 틀 2장(`mg_order_light/dark`)은 가로 그림이라 세로 주문 카드에 늘어나 보여서 빼 두었어요(`embed_assets.py`의 SKIP).
