# 1.7.1 업적과 칭호, 새 선생님, 방 꾸밈 작업 메모

브랜치 `feat/v171-achievements` (main 1.7.0 `0b24045`에서). 그림은 1.7.1 전용 묶음 `window.FS_IMG171`(FS_IMG170 뒤 표시 사이). 넣는 법: `cd dev && python3 embed_assets.py --block 171 <폴더>`. 그림 둘레의 투명 여백은 미리 잘라서 넣었어요(선생님, 소품, 행사 그림). `IMG()`와 `FSI()`가 FS_IMG 다음에 FS_IMG171도 찾아요.

## 업적과 칭호 (ACH)

- 종류 12개 × 5단계(동, 은, 금, 백금, 무지개). 보상은 단계마다 황금 도토리 1, 2, 3, 4, 5개(종류마다 15개, 모두 180개). 숫자와 칭호 이름은 `ACH` 한곳.
- 재는 값은 이미 있는 기록: 학생 수, 종업식과 졸업식(`S.st.grads`), 가장 높은 건물 레벨, 연수 횟수(`S.st.trains`, 새 선생님과 교감 선생님 연수 포함), 메인 퀘스트(`S.q.m`), 퍼즐 최고 점수, 도감 칸, 학교 행사(운동회 + 행사 횟수), 출석(`S.att.n`), 체험학습, 모은 황금 도토리(`S.st.gold`), 학교 파워.
- 저장 `S.ach = { hit, got, title }`. 1초마다(`tick170` → `tick171ach`) 이룬 단계를 `hit`에 적고 알림, 받기 버튼으로 `got`까지 보상. 학생 수처럼 줄어드는 값도 한 번 이룬 단계는 남아요. 예전 저장은 도감을 열 때 알림 없이 기록으로 채워요.
- 칭호: 5단계를 이루면 받아요. 처음 받은 칭호는 바로 달아요. 업적 화면 위 칩을 눌러 바꾸거나 떼요. 홈 위쪽 학교 카드("1년째" 줄 오른쪽)에 리본으로 보이고 누르면 업적 화면이 열려요. 랭킹 내 줄 이름 옆에도 보여요.
- 랭킹 서버: `forest/rank/<id>/title`(업적 종류 id, 영어 소문자 12자까지). 서버 규칙에 칸을 더했어요(`database.rules.json`). **Firebase 콘솔에 새 규칙을 게시해야 해요.** 게시 전에는 칭호가 든 랭킹 쓰기가 거절돼요(그때는 `ACH_RANK_TITLE`을 false로).
- 자리: 오른쪽 세로 버튼은 늘리지 않고 동물 도감 창 위 "동물 도감 / 업적" 두 칸(`setDexSeg`). 받을 업적이 있으면 도감 버튼과 업적 칸에 빨간 점.
- 그림: 작업지시서 6(20장). 백금과 무지개 테두리는 금 테두리에 CSS 색을 입혀요(`tint-plat`, `tint-rainbow`). 전용 그림 `ach_frame_platinum`, `ach_frame_rainbow`가 오면 저절로 그걸 써요. `ic_trophy`는 아직 안 써요(나중에 업적 버튼을 따로 만들 때).
- 1.8.0 머지 게임 업적은 `ACH`에 한 줄 더하면 돼요.

## 새 선생님 (XT)

- 양 영양 선생님(`diet`, 급식실), 사슴 사서 선생님(`lib`, 도서관). 그 건물을 지으면 학교에 오셔요(Lv.0). 교감 선생님처럼 따로 연수, 값은 곰 연수 곡선, 최고 Lv.10. 수업료 계산(rate)과 추천에는 안 들어가요.
- 영양: 까치 특식 데이(`DEAL.feastMin` 20분)가 레벨마다 +2분(`feastMins()`, Lv.10 40분). 상점의 특식 데이 10분은 그대로.
- 사서: 숲속 퍼즐 점수 정수가 레벨마다 +3%(`libMult()`, Lv.10 +30%). 학생 부탁 정수는 그대로.
- 저장 `S.xt = { diet, lib }`. 선생님 탭 교감 선생님 밑에 카드 두 장. 도감 선생님 칸 두 칸(모두 17종, ??? 자리는 1칸 남음).

## 방 꾸밈 소품과 걷는 친구들

- 소품 25개(작업지시서 8): 건물 Lv.1, 5, 10, 15, 20이 되면 하나씩(`PROP_AT`, `PROP_LAY`). 자리는 Codex 미리보기 배치를 따라 잡았어요. 벽에 거는 것과 러그는 가구보다 뒤에 그려요.
- 걷는 친구들(`WALK`): 방 안 길을 오가며 가끔 멈춰요. 그 방 선생님(교실 다람쥐, 급식실 영양, 도서관 사서, 운동장 곰, 과학실 부엉이)은 모셨을 때만, 학생은 두 명. 가구 위, 이름표 아래에 그려요. `rt.walk`, 매 프레임 `tick171`.

## 행사와 손님 그림

- 작업지시서 9(17장): 보물 쪽지, 풍선 세 색, 음표 두 개, 웃음 별, 운동회 공(운동회 중 떨어지는 것), 학예회 무대, 사진기, 환영회 줄 장식(새로 걸어요), 행사 아이콘 5개. 누르는 자리와 크기는 그대로, 그림이 없으면 예전 도형.
- 지도에 오는 뱀, 매(시련)와 까치(핫딜 아이콘, 창)는 1.7.0 도감 그림(`chr_snake` 등)으로.
