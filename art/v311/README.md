## 제작과 확인

모든 그림은 GPT 이미지 생성 기능으로 제작했습니다.
이후 시트 분리, 위치 맞춤, 캔버스 배치와 크기 조정을 했습니다.
코드로 그림을 그리거나 색 필터로 그림을 만들지 않았습니다.

첫 아이콘/장식 시트에 남은 넓은 회색 안개는 이미지 생성 편집으로 제거했습니다.
등불은 종이 몸통을 키우고 넓은 흰 빛 번짐을 줄이도록 다시 생성했습니다.
원본 알파를 보존했고 흰색을 기준으로 배경을 지우지 않았습니다.
흰 촛불, 반딧불 날개, 유리병 테두리와 반짝이는 부분이 남아 있는지 짙은 바탕에서도 확인했습니다.

- 별똥별은 머리가 오른쪽 아래, 꼬리가 왼쪽 위입니다. 두 그림을 같은 배율로 내보냈고 머리 기준점은 최종 캔버스의 약 `(180, 180)`에 맞췄습니다.
- 등불 세 장은 같은 자르기 범위와 배율을 사용했습니다.
- 반딧불 두 상태는 밝기가 다른 빛 번짐 대신 몸의 진한 실루엣을 기준으로 가운데를 맞췄습니다. half는 약하게 빛나는 그림이며 전체 이미지 밝기가 수치상 정확히 50%라는 뜻은 아닙니다.
- 작은 크기는 30px 최대 변 기준으로 확인했습니다. 세로형 등불은 30px 높이로 표시됩니다.

## 출처와 기록

기존 행사 아이콘 3장, 지도 장식 2장과 밤 장식은 현재 게임 그림 묶음에서 추출했고, 지도는 `img/maps/map_high.webp`를 그대로 복사했습니다.
`ref/`는 복사 후 수정하지 않았습니다. 출처와 해시는 `references.json`에 있습니다.
생성 원본은 `/workspace/generated_images/`에 보존했으며, `assets-manifest.json`에 원본 식별자/해시와 자른 범위, 위치 이동을 기록했습니다.

그림 전달용 브랜치와 PR입니다. `main`이나 `fix/fest-donate`에는 합치지 않습니다.
그림 키 삽입, 행사 활성화, 3.1.1 시험과 업데이트는 포함하지 않았습니다.
