| 검사 | 결과 |
| --- | --- |
| a. 크기와 색 방식 | 게임 PNG 42장: 기본과 겨울 지도 12장 및 나무 지운 지도 10장은 RGB, 참나무 10장은 RGBA, 가림판 10장은 L. 모두 1024×1536. 확인 PNG 9장은 긴 쪽 1600px 이하. `deliverables.json`에 10묶음 좌표와 검사 결과. 전체 53파일. |
| b. 빈터 가운데와 너비 | 기본은 같은 색 기준의 흙 내부 타원, 겨울은 눈 속 돌 테두리 안쪽 경사를 찾아 타원 비교. 기본과 겨울을 합친 구역별 가운데 거리/너비 최대 차이: 학술 4.0/2.1px, 생활 1.0/4.0px, 광장 1.4/0.5px, 체육 0.8/1.3px, 연구 3.1/1.6px. 모두 6px 이내. 체육 겨울 타원은 위치 보정 후 검사. 길과 입구, 광장은 원본 윤곽을 겹쳐 확인. |
| c. 대학원판 분위기 | 캠퍼스와 학술 기본판은 승인된 87-2 파일을 이름만 바꿔 바이트 그대로 복사. 나머지도 이미지 생성으로 노을, 이끼 낀 회색 돌길, 고목 숲과 작은 조명, 구역별 연구 정원 소품을 그림. 휴대폰 크기에서 대학교와 비교. `phone.png`는 실제 가로 412px를 유지하며 1600px 제한을 지키기 위해 3장+2장 두 줄 배치. |
| d. 겨울 배치와 식별 | 기본판과 같은 자리의 눈, 서리, 분홍과 연보라 겨울 노을. 빈터 테두리와 회색 돌길을 노출하고 온실, 가스등의 따뜻한 빛 유지. 대학교 겨울 지도와 나란히 확인. |
| e. 참나무 층과 합성 | 10묶음 모두 알파 0/255, 구멍 0, 연결 덩어리 1. 가림판을 만들고 원본 RGB를 그대로 추출. 이미지 생성으로 나무를 지운 배경을 가림판 안에만 채움. 바깥 변경 0픽셀, 재합성 차이 0픽셀. 잎 끝과 눈의 잔상 방지용 작은 주변 여백 포함. 기존 바닥 화단과 돌은 배경에 남김. 원래 밑동 회전점을 유지해 좌우 2도 합성 확인. main의 `oakp`는 주변 배경을 포함한 교체판이므로, JSON에 요청한 `oakp` 가운데 차이와 실제 `oakl` 나무 자리와의 차이를 둘 다 기록. |
| f. 글자, 숫자, 기호 | 게임 그림에 새 문자, 숫자, 로고, 안내 기호와 학생 없음. 캠퍼스 원본의 시계 바늘 등 그림 장식은 유지. 확인 그림에만 이름과 선 사용. |
