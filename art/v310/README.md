기준: `feat/v310@2671b09`. 작업 브랜치: `art/v310`.
새 파일은 모두 `art/v310/` 안에 있으며 기존 파일과 게임 코드는 변경하지 않았습니다.

카드는 모서리 바깥이 투명하고 틀 안쪽의 장면과 이름 띠는 불투명합니다.

## 제작

모든 그림은 GPT 이미지 생성 기능으로 제작했습니다.
이후 시트에서 개별 그림을 자르고, 캔버스에 배치하고, 지정 크기로 내보냈습니다.
코드로 그림을 그리거나 색 필터로 화풍을 만들지 않았습니다.
흰색을 기준으로 배경을 지우지 않고 생성된 알파를 유지했습니다.

- 코끼리는 네 장을 함께 생성해 같은 캐릭터로 맞췄습니다. 세 상담 표정은 같은 배율로 배치했고, 최종 384px 캔버스에서 몸 가운데 x=191.5, 아래 기준선 y=352입니다. 몸에 맞춰 배치했으며 고개와 코의 작은 변화는 표정의 일부입니다.
- 진로 카드 12장은 같은 380×508 바깥 틀을 384×512 캔버스의 (2,2)에 배치했습니다. 아래 약 1/5 이름 띠는 비어 있습니다.
- 배지 일부에 옆 테두리가 섞인 것을 발견해 여백이 넓은 시트로 다시 생성했습니다. 최종 배지는 이 새 시트에서 내보냈습니다.
- 의사 카드의 가방 표시는 이미지 생성 편집으로 작은 잎 그림으로 바꿨습니다.
- `react_question.png`는 문자를 쓰지 않고 휘어진 물방울과 작은 땀방울로 그렸습니다.

## 기준과 기록

`ref/`는 비교용 복사본이며 복사 후 수정하지 않았습니다.
현재 게임의 선생님 2종, 학생 12종, 기숙사 방, 도감 카드 틀을 그림 묶음에서 PNG로 추출했습니다.
복도 그림은 `origin/art/hall2:art/hall2/hall/hall_bg.png`를 그대로 복사했습니다.
`references.json`에 출처와 해시를, `assets-manifest.json`에 생성 원본 식별자와 해시, 자른 범위와 배치 방법을 기록했습니다.
생성 원본은 작업 환경의 `/workspace/generated_images/`에 남겼습니다.

요청에 따라 검토용 PR만 만듭니다. `main`과 `feat/v310` 모두 병합하지 않습니다.
