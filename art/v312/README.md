# 작업지시서 52: 코드 그림 교체용 PNG 31장

받을 가지: `art/v312`. 기준: `main@5437619` (3.1.1).
기존 게임 코드와 기존 파일을 수정하지 않고 `art/v312/`에 새 파일만 추가했습니다.

31장 모두 배경 투명 RGBA PNG입니다. 글자, 숫자, 수량/배수 표기나 로고를 넣지 않았습니다.
시계에는 숫자 없이 바늘과 움직임 흔적만 있습니다. 반짝이는 빛, 실제 시계 바늘, 별 모양 전구와 빈 깃발은 사물 그림의 일부입니다.

## 제작

모든 원화는 GPT 이미지 생성 기능으로 만들었습니다.
내보내기에서는 시트 분리, 위치 맞춤, 캔버스 배치와 지정 크기 조정만 했습니다.
미리보기는 생성된 PNG와 변경하지 않은 기준 학생을 합성했습니다.
코드로 그림을 그리거나 색 필터로 원화를 제작하지 않았습니다.

- 모자는 기존 색 구분을 참고했습니다. 파란 야구 모자, 빨간 털모자, 보라 베레모, 초록 벙거지입니다.
- 꽃 머리띠는 학생 머리 위에서 떠 보이지 않게 긴 U자 양끝을 없애고 낮은 꽃 띠로 다시 생성했습니다.
- 새 모자 7장의 공통 머리 접점은 `(128,240)`입니다. 아랫단이 캔버스 아래 가운데에 오도록 맞춘 새 규격입니다.
- 목 장식은 정면에서 가운데 정렬했습니다. 목도리/목걸이의 빈 공간은 투명하게 유지했습니다.
- 처마 띠는 일곱 행 사이의 빈 곳에서 나눠 꽃잎이나 고드름을 자르지 않았습니다. 최종 그림 영역은 512×96 캔버스의 `(12,6)~(500,90)`입니다.
- 흰 김, 부엉이 깃털과 책 종이, 달, 고드름, 흰 꽃과 전구 하이라이트는 흰색을 골라 지우지 않고 생성된 알파를 유지했습니다.

## 코드 연결 때 확인할 점

이 PR은 그림 전달용입니다. PNG 키를 게임에 넣거나 SVG 사용처를 바꾸지는 않았습니다.

1. 현재 `hatSVG()`는 `HATS[id]` SVG를 PNG보다 먼저 선택합니다. 새 그림 키만 추가하면 기존 SVG가 계속 나오므로, 해당 일곱 모자의 PNG 선택 순서를 바꿔야 합니다.
2. 기존 산타 모자의 안내는 512 캔버스의 y=360입니다. 이번 새 모자는 요청에 따라 아래쪽 접점 `(128,240)`에 맞췄으므로 기존 산타용 이미지 오프셋을 그대로 쓰지 말고 접점에 맞춰 놓습니다. 기준 산타 그림과 게임 코드는 변경하지 않았습니다.
3. 목 장식은 현재 `kidSVG()`에서 `NECKS` SVG를 직접 넣습니다. 새 PNG를 읽는 연결이 필요합니다. 미리보기에 쓴 목 접점과 학생별 확인 좌표는 `_preview/fit_coordinates.json`, 그림 배치/크기는 `assets-manifest.json`에 있습니다. 미리보기 좌표는 실제 게임 좌표 설정을 대신하지 않습니다.
4. 부스터, 창 그림, 테마 칸과 처마 띠도 각 사용처에 그림 키를 연결해야 합니다.

게임 코드 변경이 없어 게임 회귀 시험과 웹/Android/토스 빌드는 실행하지 않았습니다.
버전, 패치노트, 재화와 저장 구조도 바꾸지 않았습니다.
검토용 PR만 만들며 main에는 합치지 않습니다.

## 기준과 기록

`ref/`는 현재 게임의 모자 3종, 학생 2종, 부엉이 선생님, 부스터 2종, 교실과 건물 아이콘 5종, 지도 1장을 복사/추출한 자료입니다. 복사 후 수정하지 않았습니다.
`references.json`에는 출처와 해시, `assets-manifest.json`에는 원화 식별자/해시와 자른 범위 및 위치를 기록했습니다.
생성 원본은 `/workspace/generated_images/`에 남겼습니다.
