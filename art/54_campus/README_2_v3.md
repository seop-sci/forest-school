# 작업지시서 54 캠퍼스 GitHub 전달판

사용 파일은 `deliverables_2_v3.json`의 `assets`를 기준으로 한다.

- 원본 게임 PNG 53장: 승인 기본 지도 5, 겨울 지도 5, 건물 34, 방/가구 5, 캐릭터 4.
- 최신 승인 자리 표 5개: campus_v2, academic_v2, life_v3, plaza_v2, sports_v3.
- 확인 그림 4개: maps.png, buildings.png, fit.png, chars.png. 긴 쪽 1600px 이하.
- README와 deliverables 2개를 합쳐 총 64개 파일.
- 원본 PNG는 다시 인코딩하지 않고 바이트 그대로 복사했다. 크기·색·위치·투명도와 SHA-256이 원본과 같다. 승인 기본 지도와 자리 표를 수정하지 않았다.
- 건물·지붕 1024×1024, 지도 1024×1536. room_union 900×600, 가구 512×512. 학생 150×220, 학장 195×260.
- 도서관 지붕은 `_v2`가 최신이다. 다른 파일 키와 실제 경로는 manifest를 따른다.
- 참나무 관련 파일, 생성 원본, 중간 작업 파일, 비밀값은 이 묶음에 포함하지 않는다. 50MB 초과 파일은 없다.
- 그림은 이전 54번 2단계 내장 image_gen 결과를 사용했다. 이번 전달에서는 그림을 새로 생성하거나 원본을 편집하지 않았다.

가지 `art/54-campus`는 main에서 별도로 만들며, main 병합과 PR은 하지 않는다.
