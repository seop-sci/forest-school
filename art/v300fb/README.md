## 제작과 내보내기

모든 그림은 GPT 이미지 생성 기능으로 만들었습니다.
시트에서 개별 그림을 자르고 크기를 맞췄으며, 비버 전신 3장은 같은 배율로 옮겨 발 위치를 맞췄습니다.
미리보기의 배치, 파일 이름, 안내선은 확인용 합성입니다.
코드로 그림을 그리거나 색 필터로 그림을 만들지 않았습니다.

트랙을 뺀 70장은 RGBA PNG이며, 이미지 생성 결과의 투명도를 보존했습니다.
흰색을 기준으로 배경을 지우지 않았습니다.
토끼풀은 세 잎으로 다시 생성했고, 멧토끼는 주변 배경이 남지 않도록 이미지 생성 기능으로 다시 정리했습니다.
세로로 긴 왜가리와 두루미는 머리 끝이 잘리지 않도록 원본 시트에서 자르는 범위를 따로 잡았습니다.

`assets-manifest.json`에 71개 파일의 크기, SHA-256, 생성 원본 식별자와 해시, 자른 범위, 위치 이동을 기록했습니다.
생성 원본은 작업 환경의 `/workspace/generated_images/`에 보존했고, 이 PR에는 내보낸 PNG만 넣었습니다.

## 게임에 올릴 때

- 비버 전신은 모두 256×256 캔버스 그대로 교체합니다. 그림마다 불투명 영역에 맞춰 따로 확대하지 않습니다.
- 비버 발 기준선은 약 `(128, 239)`입니다. 알파 160 이상인 발끝은 세 장 모두 y=238이며, 발의 좌우 가운데 차이는 0.5px입니다.
- 학생보다 조금 큰 표시 크기를 사용합니다. 비교 미리보기에서는 비버 256px 캔버스와 토끼 높이 200px를 사용했습니다.
- 생물 카드는 옷과 목수건 없는 야생 생물입니다. 카드 틀은 그림에 들어 있지 않습니다.
- `bt_track.png`는 가로로 반복합니다. 좌우 흰 선의 행 위치가 같습니다. 흙의 수채 질감에는 작은 색 차이가 남으므로 좌우 픽셀이 완전히 동일한 타일은 아닙니다. 3회 반복 미리보기에서 연결 상태를 확인할 수 있습니다.
