# 3.0.0 고급 지도와 건물 12장

작업 브랜치: `art/v300-lux`.
기준 브랜치: `feat/v300`, 기준 커밋: `c034ee4`.

황금빛 궁전 정원 테마입니다. 금빛 울타리, 밝은 대리석 길과 분수, 장미 덩굴, 보석빛 물, 작은 등불을 기존 숲속 학교 화풍에 맞췄습니다.

## 파일

- `maps/map_{kinder,elem,middle,high}_lux.png`: 학교급 지도 4장, 1024×1536, 배경 있음
- `bld/bld_{classroom,cafeteria,library,science,store,dorm,field,playground}_lux.png`: 건물 8장, 400×400, 투명 배경

모든 그림은 해당 기준 그림을 입력으로 넣고 GPT 이미지 생성 기능으로 다시 그렸습니다.
내보낼 때는 전체 캔버스 크기 조정과 PNG 저장만 했습니다. 코드로 그림을 그리거나 색 필터로 테마를 만들지 않았습니다.
투명 배경은 생성 결과의 알파를 보존했고 흰색을 골라 지우지 않았습니다.

## 기준 그림

`ref/`는 읽기 전용 비교 자료로 복사했으며 이후 수정하지 않았습니다.

- 지도: 기준 커밋의 `img/maps/map_kinder.webp`, `map_elem.webp`, `map_middle.webp`, `map_high.webp`
- 건물: 기준 커밋의 `dev/forest-school.html` 그림 묶음에서 실제 사용하는 `bld_*_on` PNG 8장을 추출

`references.json`에 출처와 해시를 기록했습니다.
`assets-manifest.json`에는 새 그림의 생성 원본 식별자, 원본 크기, PNG 크기와 해시를 기록했습니다.
생성 원본은 작업 환경 `/workspace/generated_images/`에 남겼습니다.

지도는 유치원 5곳, 초등학교 6곳, 중학교 7곳, 고등학교 8곳의 빈터를 유지했습니다.
50% 겹침 그림과 나란히 비교 그림으로 길과 빈터, 호수와 물가 배치를 확인했습니다.
빈터 안은 건물과 장식 없이 평평하게 비웠습니다.
이미지 생성으로 재해석한 그림이므로 울타리 장식과 돌 무늬까지 원본과 픽셀이 같다는 뜻은 아닙니다.

건물은 기준과 같은 400×400 캔버스 전체를 사용합니다.
그림마다 불투명 영역에 맞춰 따로 확대하지 않습니다.
책 지붕, 망원경, 식당 무늬, 매점 차양, 기숙사 창과 빨랫줄, 운동장 트랙과 잔디, 놀이터 놀이기구를 작은 크기에서도 구별할 수 있도록 남겼습니다.
깃발과 장식, 흰 돌, 창과 하이라이트는 밝은 바탕과 어두운 바탕에서 확인했습니다.

게임 코드, 기존 파일, 버전과 패치노트는 변경하지 않았습니다.
게임 회귀 시험과 웹/Android/토스 빌드는 실행하지 않았습니다.
이 PR은 그림 전달용이며 `main`과 `feat/v300` 모두 병합하지 않습니다.
