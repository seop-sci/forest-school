# 54 참나무 v7 검수 전달판

원본 지도 44장을 지도마다 따로 선택한 이진 가림판으로 오렸다. 원본-nooak 차이로 층을 만든 v6 방식은 사용하지 않았다. 나무 RGB·자리·크기를 원본 그대로 보존했다.

## 파일과 사용

참나무 44, nooak 44, 가림판 44, 확인 그림 44, 문서 2: 총 178개. 게임 PNG와 마스크는 1024×1536이다. oak는 RGBA, nooak는 RGB, mask는 흑백 L이다. 모두 50MB 이하.
같은 원점에 nooak와 oak를 겹친다. pivot 기준으로 oak만 회전한다. 좌표는 가로/세로에 대한 %, 소수 둘째 자리다. tap 반지름 기준은 지도 가로 폭이다. acorns·drop 8곳씩과 원본 SHA-256은 deliverables의 oak 항목에 있다.

## 생성·합성·확인

가림판은 원본 지도에서 분할 모델과 마스크 처리로 선택했다. 내부 작은 틈을 메우고 가장 큰 연결 덩어리를 사용했다. 코드는 나무나 바탕 그림을 새로 그리지 않았다. 나무를 지운 바탕 44장은 내장 image_gen으로 새로 생성했다. 프롬프트 공통 내용은 “선택된 큰 참나무 전체를 지우고, 같은 계절·테마의 낮은 잔디/꽃/땅/눈으로 채우며 돌담·길·울타리와 다른 나무를 유지”다.
d의 정확한 재합성을 위해 최종 바탕 교체는 가림판 내부에 한정했다. 바깥 8px 확장 영역까지 원본과 달라지는 합성을 하지 않았다. 변경 허용 영역 밖 차이 0, 원본 RGB 오차 0을 검사했다.
확인 그림은 원본 → nooak → 자홍색 위 oak → mask → -6도 → +6도 순서다. 모든 판은 같은 원본 좌표를 사용한다. 이 그림에 실제 검수 잔여 문제가 보이며 숨기지 않았다.
원본 지도 44장과 승인 자리 표는 수정하지 않았다. 겨울·크리스마스의 눈·장식 및 화면 가장자리에서 잘린 원본 나무 때문에 경계 수작업 보정이 더 필요하다.

## 업로드 범위

`art/54-oak` 가지의 `art/54_oak/`에 이 178개만 배치한다. 기존 v6 관련 파일은 저장소에서 제거하고 로컬 원본은 보존한다. main 병합과 PR은 하지 않는다.
