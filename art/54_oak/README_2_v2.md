# 작업지시서 54 — 2단계 결과

최신 사용 파일은 `deliverables_2_v2.json`의 `assets`와 `oak`를 기준으로 한다. 이전 작업판은 덮어쓰지 않고 보존했다. 참나무 최종 쌍은 `_v6`, 도서관 지붕 최종은 `_v2`다.

## 만든 것

- 겨울 지도 5, 건물 34(기본 8 + 겨울 8 + 지붕 16 + 공사 자리 2), 방/가구 5, 캐릭터 4, 참나무 층 44, 나무 지운 지도 44: 새 게임 PNG 136장.
- 승인 기본 지도 5장을 합치면 게임 PNG 141장. 승인 지도/최신 자리 표와 기존 게임 지도 36장은 수정하지 않았다.
- 모든 새 그림/눈/빈 배경은 내장 image_gen으로 생성. 코드는 마스크·원본 좌표 합성·규격 내보내기·확인 그림·검사에 사용했다.

## 규격과 적용

- 지도/참나무: 1024×1536. 참나무 층을 자르거나 따로 확대하지 말고 nooak 지도와 같은 원점에 겹친다.
- 기존 36장 원본은 57번 최종 보고서가 지정한 `art/57_maps_v2`를 사용했다.
- 승인 자리 표: campus_v2, academic_v2, life_v3, plaza_v2, sports_v3. 원본 PNG와 표의 해시는 모두 보존됐다.
- 건물/지붕: 1024×1024 투명. 지붕은 밝은 회색이며 기본·겨울 모두 같은 원본 캔버스 좌표에서 추출했다. 겨울 눈 돌출부만 추가된다.
- 바닥 섬 공통 외곽 상자 [41,580,983,964], 가운데 [512,772], 942×384(꽃 외곽 포함 약 2.45:1). 실제 빈터 내부 90% 코어의 미덮임 픽셀은 기본/겨울 모두 0이다.
- 방 900×600 배경 있음, 가구 4종 512×512 투명. 학생 3종 150×220, 학장 195×260 투명. 기준 상단 여백과 발끝 차이는 각 0픽셀이다.
- 참고 WebP 4개, PNG 4개, 출처 JSON 1개는 `ref/forest-ref`에 추가했다.
