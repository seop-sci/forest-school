# 창문 불빛 조각 기준 그림 (작업지시서 42)

지금 게임에 들어 있는 건물 그림을 그대로 꺼낸 것이에요(400×400, 배경 투명). 불빛 조각은 이 그림과 같은 캔버스, 같은 자리에 맞춰 만들어요.

- 유치원(1단계): bld_classroom_on, bld_cafeteria_on, bld_library_on, bld_playground_on
- 초등학교(2단계): bld_classroom_s2, bld_cafeteria_s2, bld_library_s2, bld_science_on(과학실), bld_field_on(운동장)
- 중학교(3단계): bld_classroom_s3, bld_cafeteria_s3, bld_library_s3, bld_science_s3, bld_field_s3, bld_store_on(매점)
- 모두 겨울 모습(_winter)이 함께 있어요.
