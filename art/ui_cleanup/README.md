# 홈 UI 정리 인계 자료

이 폴더는 그림·디자인 기준·Claude용 작업 명세입니다. 게임에 연결한 구현물이 아닙니다. 기존 게임 코드와 기존 그림은 변경하지 않았습니다.

## 파일

| 파일/폴더 | 용도 |
| --- | --- |
| `CLAUDE_PROMPT.md` | 그대로 복사해 전달할 구현 요청. 저장소 구조·보존 조건·반응형 크기·검증 기준 포함 |
| `design-tokens.css` | 색·간격·크기 참고값. 게임에 자동으로 불러오지 않음 |
| `assets-manifest.json` | 원본 커밋, 기존 그림 키, 파일 크기 및 출처 |
| `reference/home_target.png` | 사용자가 선택한 이미지 생성 UI 시안. UI의 묶음·색·정렬 참고 |
| `new/ic_ui_quest.png` | 새 퀘스트 클립보드. 256×256 투명 PNG |
| `new/ic_ui_school_event.png` | 새 학교 행사 풍선. 256×256 투명 PNG |
| `reuse/` | 현재 게임에 이미 들어 있는 그림 18종을 원본 크기로 추출한 PNG. 게임에서는 기존 키를 그대로 사용 |
| `_preview/elements.png` | 새 아이콘과 기존 그림을 밝은/어두운 바탕에 놓은 검수용 미리보기 |

## 그림 사용

새 아이콘 2장만 이미지 생성으로 제작했습니다. 기존 아이콘은 내장 WebP를 PNG로 해독한 복사본이며 다시 그리거나 늘리거나 색을 바꾸지 않았습니다. 파일별 출처와 해독 픽셀 해시는 manifest에 있습니다.

패널·진행 막대·버튼·이름표·메뉴 바탕은 CSS, 텍스트·숫자는 실제 DOM으로 구현합니다. 화면 전체나 글자가 들어간 버튼을 그림으로 붙이지 않습니다. 달력·닫기·접기·평판·학생 수 등의 기존 단색 SVG 제어 아이콘은 그대로 재사용합니다. 장식용 잎·꽃도 기존 `orn_*`를 필요할 때만 사용합니다.

`reuse/`는 참고·디자인용입니다. 이 폴더 전체를 다시 임베드하면 이미 있는 아이콘이 중복되므로 새 그림을 넣을 때는 `new/`만 대상으로 삼습니다. 현재 `dev/embed_assets.py`는 `ic_`를 인식하고 기존 묶음에 새 키를 합칩니다. 실제 구현자는 최신 스크립트를 먼저 읽고 두 키 추가 외 기존 데이터가 바뀌지 않았는지 확인해야 합니다. 그림 임베드도 Claude 구현 작업에 포함되며, 이 인계 자료를 만들면서 실행하지 않았습니다.

## 시안 해석

지도·건물·동물 배치를 다시 만들라는 시안이 아닙니다. 위아래 OS 상태 표시줄도 게임 UI가 아닙니다. 지도 좌표·동물 이동·기존 이벤트·실제 데이터는 그대로 두고 UI 레이어의 배치와 색, 여백을 정리하는 기준으로 사용합니다.

특히 시안의 퀘스트 오른쪽 `410만`은 샘플 숫자입니다. 확인한 원본의 `#qbRew`는 `qReward(q)`를 표시하므로 **보상**입니다. 비용으로 바꾸지 않습니다. 원본 학교 현황을 펼치면 보이는 학생 수/정원·학교 파워도 시안에 없다고 삭제하지 않습니다.

조사 기준은 manifest의 main 커밋(게임 버전 1.7.0)입니다. Claude는 실제 착수할 최신 main의 함수·선택자·버전을 다시 확인해야 합니다.
